# DDD 战斗内核设计（v2 框架版）

> 本仓库是里程碑 v2：独立 IP、9 派系（源于九源质）+ 英雄层、压缩牌库。
> 本文档只描述**最终模型**，不写拍板过程与版本变迁（来源留在 git 提交）。
> CardGame 仓库（旧里程碑，含诡秘之主 IP 与 22 途径全量）是**只读参考源**，不在本仓库维护。

## 总览

```
┌─ 编目上下文（Catalog）────── 定义态 Def 的唯一聚合，战斗启动时整体快照
├─ 编队上下文（Roster）─────── 单位/技能槽/装备两槽/状态/召唤
├─ 战场上下文（Battlefield）── 界域压制栈 / 规则槽 / 区域 / 时钟相位
├─ 效果上下文（Effect）─────── 32 原语 + 3 算子，效果树的唯一执行语义
└─ 战斗上下文（Combat）─────── 整场战斗一聚合，伤害链/机会/资源结算
```

**依赖方向**：效果 ← 编队 ← 战场 ← 战斗 ← 编目；定义态与运行态严格分离。

## 三条架构支柱

1. **整场战斗一个聚合**：根是 Combat；对外契约 `CombatSetup → CombatEnded`。Unit 不是聚合根。
2. **纯函数契约**：结果 = f(初始状态, 输入序列, 随机种子)。Catalog（全部定义态 Def）是不可变聚合，战斗启动时快照进战斗内；随机源可播种、可快照。可复现 ≠ 禁随机。
3. **Definition + Grant 三件套**（EffectDef→EffectRef→Effect、StatusDef→StatusGrant→StatusInstance、EquipmentDef→EquipmentGrant→EquipmentInstance 等）：默认值只写 Def、实例值只写 Grant，Grant 不可变。

## 核心不变量（封闭集，跨上下文）

| # | 不变量 | 含义 |
|---|---|---|
| INV-1 | 单聚合 | 整场战斗一个 Combat 聚合；Unit 不是聚合根 |
| INV-2 | 纯函数 | 同种子同输入序列 ⇒ 逐位相同结果 |
| INV-3 | 快照隔离 | 战斗内只读 Catalog 快照；Def 在战斗中不可变 |
| INV-4 | 零随机伤害 | 伤害数值与目标选择零随机；概率只能写成条件采样（见随机性治理） |
| INV-5 | 驱散边界 | dispel 只作用于 StatusInstance；属性修正不可驱散、只按计时回滚 |
| INV-6 | 无手牌 | 进度条回合制；技能自由配置进槽；不存在抽牌/手牌概念 |
| INV-7 | 机会括号 | 行动机会有左右括号：机会获得与结束都会闭合触发（wasted 也闭合） |
| INV-8 | 装备单槽 | 武器槽/护具槽互相独立、各至多一件；同槽顶替，旧件先下线 |
| INV-9 | 无游离装备 | 装备只能由装备牌创建、只存在于单位槽位；无背包/拾取/锻造 |
| INV-10 | 装备效果随槽 | 武器攻击加值走溯源修正；护具维护护甲池；卸载即撤销 |
| INV-11 | 护甲有形门槛 | 护甲只抵消有形伤害；无形元素（精神/圣神/黑暗）与 DoT 绕过；护盾同理（护盾挡非 DoT 的任意元素） |
| INV-12 | 装备 CD 后置 | 装备牌 CD 于装备下线后才开始计；同槽全部装备牌公用 CD（基数=下线卡面 CD×下线系数） |
| INV-13 | 召唤位 | 每施法者有召唤位上限；超限 = 最早在场召唤物消散（不走死亡链） |
| INV-14 | 界域压栈 | 界域分层压制：上层被解除后下层恢复；基层不可驱散 |
| INV-15 | 规则槽定长 | 战场级规则槽定长 3；写入/改写/移除全部走原语，不留后门 |
| INV-16 | 状态类别二元 | 状态类别只有正向 buff / 负向 debuff 两大类（其余为机制标签） |
| INV-17 | 原语封闭 | 效果原语 32 个封闭集，以 schema effect.oneOf 为权威；新增须先登记 SCHEMA.md §5 封闭集清单 |
| INV-18 | 触发点封闭 | 触发点 16 个封闭集；主动/召唤卡的顶层 triggers 不是合法载体 |
| INV-19 | 抗性钳制 | 抗性取值钳制 [-50%, +75%]、档位 10% |
| INV-20 | 位移正交 | 射程（reach）与选靶（targetSpec）正交；击退走行动条数值，不是位移原语 |

数值锚点与平衡参数**不在**本册；随英雄迁移逐批登记于 `params/编队参数.md`。

## 随机性治理（R1–R6 摘要）

- 伤害/目标选择零随机（INV-4）；概率一律写成条件节点 `{kind:'chance', p}`，须登记、单次抽样、只用于非伤害维度。
- 落空/阻挡语义一律用 charges 次数型状态的确定性写法，不开概率例外。
- 重排类效果（行动条/状态轮转）是数值集合守恒重排，不产生新随机量。
