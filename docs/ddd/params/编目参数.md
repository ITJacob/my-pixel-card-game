# 编目参数与取值域

> 编目上下文机制层的取值域与纪律：展开纪律（原术语层的 v2 落点）、SkillDef 元标记、模板优先 + 逃生舱。Def/Grant 归属与 `$extends` 继承见 `contexts/编目上下文.md`；字段级结构权威是 `docs/json/schema/skills.schema.json`。v2 无独立术语字典层（无 TermDef 池）——术语纪律落在 3 算子的编目期行为上。

## 一、展开纪律（原术语层的 v2 落点）

- `sequence` 编目期展开为扁平 EffectRef 序列，运行期引擎零感知；展开在校验时一次性完成，运行期不再解析嵌套结构。
- `repeat` 动态段数：`countFrom:'statusStacks'` + `statusId` 读持有层数；按上限（maxStacks / countMax）编目期展开，运行期按实际值执行前 N 段——「层数段数」「按 debuff 条数累加」依此语义。
- **多段共享坐标**：repeat 默认共享同一冻结坐标（`shareTarget`），段间不重新解析目标；目标死亡则后续段落空。
- **文案同步**：展示文案由实际生效参数渲染，禁止与实参脱节——真打三下就必须显示三下，或改名。
- **互斥概率分支**：写成嵌套 if 链（各分支 condition 互斥、抽样只在判定处读一次，R4）；禁止并列多个独立概率 if（叠加触发）。细节见 `contexts/随机性治理.md` §三。
- **跨效果传值**（吸血等）不走算子内传参，做成独立原语（drain）。

## 二、SkillDef 元标记

| 标记 | 取值 | 说明 |
|---|---|---|
| `tags` | string[]，开放 | 风味与流派检索标签，也是规则增强按 tag 过滤的读取面；`$extends` 继承取父∪子并集（`contexts/编目上下文.md`）；新风味一律走 tags，不新开元素或字段 |
| `authority`（权柄） | boolean，默认 false | 权柄标记：schema 暂未设字段，旧机制登记于此，复活 echo 限制时补登记。机制语义：模仿/复制/重放类效果（echo_last_skill 等）默认排除权柄技能；纯数据标签，不参与结算 |

## 三、模板优先 + 逃生舱

- 技能定义**优先 `$extends` 复用**父定义（只覆写差异字段），享复用与继承 tag 查询；**无法模板化的**允许不带 `$extends`、由卡自带完整定义——特异技能有出路，不堵死。
- **战内分支选择**（三选一/四选一）：正典 = 卡面顶层分支结构（if / 分支 sequence），不立变体（modes）机制；战外构筑变体归战外上下文，不进战斗内核。
- **流派** = 基于 tags/元素的查询规约（如「含某 tag 的技能 ≥ 2」），纯查询，不进战斗。

## 四、数值单点

默认值与上下限只在 Def，实例值只在 Grant/params；任何重复定义视为配置错误（Def→Grant→Instance 三件套，见 README）。卡面只写实例参数，unitType/基线/技能组由顶层蓝本池兜底，不两写。
