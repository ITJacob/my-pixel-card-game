# 召唤物参数

> 召唤单位（unitDef 蓝本）的定义权威：种类归属（unitType 枚举）、属性基线（H1 四参）、技能模型、克制承载。召唤行为本身（spawn 原语参数族、落位）权威在 `效果参数.md` 原语表；召唤位上限与维持费权威在 `编队参数.md` 召唤位节。本文只回答「召唤出来的是什么」。

## 一、unitType 枚举（12 值封闭集）

unitType 是**编目层 unitDef 属性**，不是 Unit 运行时字段；运行时判定一律走 filter/谓词（`共享内核参数.md` 谓词表与 filter 维度表）。filter.unitType 的 schema 侧是开放 string，本文为其值域权威。

| unitType | 判别要点 |
|---|---|
| UNDEAD | 尸骸唤起，死灵系产物 |
| SPIRIT | 无实体之灵、被外放/放牧的灵魂 |
| BEAST | 活体驯化或召来的动物 |
| VERMIN | 低血快攻小体群 |
| PLANT | 催化/催生的植物 |
| CONSTRUCT | 人手工坊造物（材质/阶梯体系） |
| MACHINE | 精密机械结构（与造物的手作相别） |
| FLESH | 血肉拼/育成的仆役 |
| DEMON | 深渊/仪式投影 |
| ABERRATION | 灵界生物、不可名状之异变 |
| ILLUSION | 影、镜像、空想/历史之影，非真存 |
| ITEM | 物而非战力（攻击恒 0 或近 0） |

- 具名单位蓝本集中于各文件顶层 `unitDefs` 池（同文件多卡共享），Catalog 快照时随文件整体入编目。
- 跨卡/跨文件复用同一 unitId 时**种类恒定**，差异只许出现在 spawn 实例参数上。
- 召唤物身份判定走 filter `isSummon`（`共享内核参数.md`），不设身份状态、不另立嘲讽式身份标签。

## 二、属性：H1 基线四参

**合成公式**：`最终属性 = unitDef base（按 unitType 基线档） × spawn 段比率`。比率缺省 = 1.0（按 base 原值出场）。

**取值规则**：`hpRatio`/`atkRatio` 可写在两处——**unitDef 持有单位缺省比率**（schema 同名字段，如 unit_marionette hpRatio 0.25 / atkRatio 0.4），**spawn 段可覆写**为 per-spawn 实例参数；同一 unitId 跨卡比率不一致属正常定价差异；冲突时以 spawn 段显式值为准，unitDef 值只兜底缺省段。

| unitType | hp 基线 | atk 基线 | reach | 亡语/离场载荷默认 |
|---|---|---|---|---|
| UNDEAD | 12（坦克变体 24） | 3（坦克 2） | 近战 | 无 |
| SPIRIT | 14 | 3 | 近战 | 无 |
| BEAST | 10 | 4 | 近战 | 无 |
| VERMIN | 6 | 2 | 近战 | 毒（卡面带） |
| PLANT | 16 | 2 | 近战 | 坚守/纠缠 |
| CONSTRUCT | 14 | 3 | 近战 | 材质档差异 |
| MACHINE | 14 | 4 | 近战 | 无 |
| FLESH | 12 | 3 | 近战 | 回血（卡面带） |
| DEMON | 16 | 5 | 近战 | 无 |
| ABERRATION | 18 | 4 | 近战 | 全场伤（卡面带） |
| ILLUSION | 8 | 3 | 近战 | 短寿/消散 |
| ITEM | 10 | 0 | — | 功能型（推条等） |

- 属性以 hp/atk 绝对值写在 unitDef base，缺省比率随 unitDef 同行登记；召唤物 reach 默认近战，远程召唤物档待平衡期再开。
- 数值锚点随英雄迁移逐批登记于 `编队参数.md`，本表只定基线口径。

## 三、技能模型三模式

召唤物的「会什么」只有三种来源，不得混出第四种：

1. **蓝本自带**：unitDef 显式声明行为/技能载荷（triggers 与技能组声明）。声明了什么就有什么，没声明就没有。
2. **模板继承**：`spawn.template` = 源单位时，属性按比例 + 完整技能组快照复制，除非显式覆写；`inheritSkills:true` 是此模式的显式开关。动态模板（killed_unit / primary_target / holder）均属此模式，取值源 = 被击杀者 / spawn 主目标 / 触发宿主。同一 spawn 同时带 `unitId` 时，unitId 只定身份（unitType/element/tags/triggers），属性与技能仍取模板源；**未给 `hpRatio`/`atkRatio` 时不做属性继承**（只取身份，不复制英雄属性）。unitDef `baseOn` 是蓝本侧同义声明。
3. **白板纯战力**：unitDef 无技能声明且无模板——只有常规攻击行为。高属性白板单位即此模式的锚。

**口径**：

- 「常规攻击行为」是所有单位的默认行为槽，不计入技能组、不占技能声明。
- 登场/消散/亡语载荷走 `triggers`（16 封闭触发点，`执行参数.md` 触发点表），不是技能。

## 四、克制承载（不新增原语）

克制特定召唤物走既有承载，谓词与 filter 的权威在 `共享内核参数.md`：

- `target_unit_type` 谓词：if 分支按 unitType 分流。
- `target_is_summoned` 谓词：按「是否召唤物」分流，不细分种类。
- 类型乘区分流：damage 原语（effDamage）无 filter 字段（schema 源同），按 unitType 增减伤走 `target_unit_type` 谓词 if 分支；持续型类型克制经状态修饰 damageBonus/damage_taken_mul 的 filter.unitType 承载。

退化方案：暗/不死类单位预置负抗性，不另立克制字段。filter 不区分敌我——克制还是加益只由效果方向决定。

## 五、召唤参数族与边界红线

- **键名**：`unitId` = 静态具名单位引用（唯一正键，原 `unit` 键已并入）；`template` = 动态模板或固定蓝本 template 名；`reviveOf` 不产生新单位（复活语义）。键名全集以 schema spawn 分支为准。
- **summon_cap**：每施法者召唤位上限；超限 = 最早在场者消散（解散路径，不走死亡链、不计死亡簿），基数与特权权威在 `编队参数.md` 召唤位节（INV-13）。
- **companionBuff**：召唤物自带增益 EffectRef[]，已登记的承载，等待首张用它的卡。
- **summonMapping**：状态层数 → 召唤强度/数量映射，对象只许是具名单位；映射值覆盖 spawn 段比率时以显式者胜（同 §二）。
- **红线**：召唤物（有血量、占格、可被攻击）与 Zone（纯坐标效果、不占格）的判别权威在 `战场上下文.md`；Zone 注册段不得借用 unitId 键。
