# 编队参数

> 卡型/状态/装备/召唤的取值域。数值锚点随英雄迁移逐批登记，本册只定结构。

## 卡型（kind 四型）

| kind | 必填 | 说明 |
|---|---|---|
| active | cost / reach / target | 主动施放，占主动槽 |
| passive | hook | 触发钩子唤起；可有 initialEquip |
| equipment | cost / equipment 载荷 | 打出即装备；武器/护具两槽 |
| summon | cost / summon 载荷 | 打出即落场，引用 unitDef 蓝本 |

- **归属**：由所在文件层级定，卡上不带归属字段——派系公共卡（`fNN_` 前缀）落 faction_NN 文件，英雄独自卡（`hNN_` 前缀）落 hero_NN 文件，跨派系复用卡落 global 文件；编队只从本派系文件组 + global 取卡。
- 装备/召唤卡的 `effects` 为可选战吼；召唤卡禁含 spawn 段之外的多单位（一卡一单位）。

## 状态类别与机制标签

- 类别二元：buff / debuff（INV-16）。
- 机制标签（开放但登记制）：control / stance / conceal / dot / aura / reactive 等；标签服务过滤与联动，不构成独立类别。
- 叠层：stackPolicy（refresh 时长刷新 / reject 拒绝重挂 / stack 并存）；层数恒按 maxStacks 钳制。

## 装备槽（EquipmentSlot）

| 槽 | 载荷 | 寿命 |
|---|---|---|
| weapon | attack（加值）+ durability | 普攻消耗耐久，归零下线 |
| armor | armor（护甲池容量） | 池空下线；卸下清零 |

- 同槽单实例、互相独立、顶替旧件（INV-8/9）。
- 装备标签 tags 开放词汇（sword / plate …），供谓词与选靶过滤。
- 持有判定谓词 has_equipped：side + 可选 slot / id / tag；缺省不点名具体装备。

## 召唤位

- 上限 = max(绝对覆写, 基数 + 加成)；基数全局定值，随平衡登记。
- 特权 = 维持费型（每 tick 资源供给换额外召唤位，断供收敛）。

## 伤害链门槛

- 护盾：挡任意元素的非 DoT 伤害。
- 护甲：只挡有形伤害；精神/圣神/黑暗元素与 DoT 绕过（INV-11）。
- 破甲 = 按比例削护甲段有效性；削护甲池走 modify_resource(armor) 负值。

## 单位属性与位格

- 基础属性：力量/敏捷/智力；位格 rank 是独立维度（钳制下界 0，上界随平衡登记）。
- 抗性：按元素开槽，[-50%, +75%]、档位 10%、支持全元素通配。
- 性别/迷失值等维度随英雄迁移登记。
