# 共享内核参数

> 条件谓词/目标系统取值域（封闭集，schema $defs 为机器权威）。

Def/Grant 归属见 `../README.md`。条件谓词只读，不产生副作用。

## 一、目标系统（unitRequest / cardTarget）

> 选靶请求的字段取值域。cardTarget = selectionMode + request + fallbackSort + consumption。

| 字段 | 取值 | 说明 |
|---|---|---|
| mode | unit / area | 第一级分流。unit（缺省）= 池为单位实体：scope 只作池边界、pickCount 定命中数，「不可被选中」类排除在此生效；area = 池为 anchor+scope 圈定的坐标区块，命中区域内全部在位单位（AoE），pickCount 不参与——**AoE 判据是 mode:area，不是 pickCount** |
| faction | self / ally / enemy / any / none / self_or_ally | any = 不限阵营纳入候选（有目标，阵营不限）；none = 无目标对象，候选池为空、I 节点直接跳过。二者语义不同不可互换 |
| anchor | self / caster / enemy_front / ally_front / enemy_back / specific_unit / spawned_unit / last_dead_ally / fixed_cell | 只回答「从哪量几何」，不承载阵营/排序/位置。缺省按 faction 推导：enemy→enemy_front（敌同路排首），ally/self→self。caster = 释放者（作用者≠触发者场景）；enemy_front = 敌同路排首 i=0；ally_front = 我方同路排首；enemy_back = 敌同路最后排；specific_unit = 指定单位；spawned_unit = 本次登场新单位；last_dead_ally = 最近阵亡友军（复活寻址）；fixed_cell = 绝对站位坐标。动态寻址（带参形式）为字符串 |
| scope | point / front_n / behind_n / cross_lane / cross_lane_row / diamond_n / chain_n / whole_lane / board / none（n 见 schema pattern） | 几何范围，自 anchor 原点量起，与 pickCount 正交。whole_lane = 被施法侧半场 4 格（缺省）；board = 全场；point = 仅锚点格；front_n/behind_n = 锚点含前/后 n 格（front=朝中线，behind=朝己方后排；敌锚点 behind_n = 前 n 敌）；cross_lane = 同 index 另一路 1 格；cross_lane_row = 另一路整条半场 4 格；diamond_n = 曼哈顿距离≤n；chain_n = 沿相邻/链接跳跃 n 次；none = 无目标 |
| sort | none / hp_asc / hp_desc / atk_asc / atk_desc / index_asc / index_desc / energy_desc / armor_desc / buff_count_desc / debuff_count_desc / gauge_asc / gauge_desc / stat_max_desc | 扩展排序键统一带 `index_asc` 确定性破平 |
| sortKey | `status:<id>:asc` / `status:<id>:desc` | 参数化状态键：按「是否持有指定状态」排序；asc = 持有者排后（降权），desc = 排前（优先命中）。不新增 weight 字段 |
| spread | none / lane_line / splash_adjacent / splash_behind / cross_same_index | **应用时点：主目标已定（auto 截断 / manual 选定）之后**，自 committedTargets 向外扩散；溅射目标不进候选池、不触发二次排序或玩家选择 |
| pickCount | int / all | mode=unit 命中数：整数 = 取 N，all = 池内全部；缺省 1。mode=area 不参与 |
| selectionMode | auto / manual | manual = 玩家手选（候选数 > pickCount 时等待）；auto = 引擎按 sort/fallbackSort 取前 pickCount |
| fallbackSort | 同 sort 取值域 | manual 时必填，用于 AI / 状态触发 / 超时 |
| consumption | instant / zone / summon / domain / translocate | mode=unit 强制 instant 或 translocate；mode=area 必填、无默认值 |
| excludeSelf / excludeAnchor | boolean | 排除施法者自身 / 锚点所在格（unit 与 area 均生效）；二者独立，`behind_2 + excludeAnchor` = 锚点后 1 格、不含锚点 |
| filter | unitFilter（见 §四） | 参数化过滤，与候选池排除机制共用 |

**默认目标基准**：mode:unit + faction:enemy + anchor:enemy_front + scope:whole_lane + sort:index_asc + pickCount:1——普攻及未显式声明目标规格的近战类伤害行为，缺省打「敌方同路最前排」。显式 targetSpec 声明优先；嘲讽 force 普攻 + target_override 在选靶节点覆盖本缺省。

**EffectRef.target 书写简写**（非新原语，由 faction + scope + sort + filter 组合展开）：self / caster（≠ self：被动/链接/转移场景「作用者」≠「触发者」）/ target（当前效果指向，多目标时不等于 primary_target）/ primary_target / same_target（与上一段同一目标）/ secondary_target（卡级第二组选靶，逐组解析取并集；未填回退主选靶）/ attacker（on_take_damage 语境发起者）/ holder / status_holder（状态或触发器持有者自身）/ killed_unit（on_kill 语境被击杀单位）/ all_allies / allies_except_self / all_enemies / all_other_enemies / all_units / all / enemy / adjacent_enemy / occupant_ally / occupant_enemy（Zone 占位单位）/ splash_adjacent / splash_behind / one_own_snare_trap / rule_breaker（规则槽 punish 载荷语境违约单位）/ board（战场级锚点，承载战场量表写入 secrecy/order/fate_value）。

## 二、元素属性

| 字段 | 取值 | 说明 |
|---|---|---|
| EffectDef.element | fire / ice / poison / lightning / mental / physical / holy / dark / none | 八元素 + none，纯标签（`$` 前缀 = 运行期变量引用）；可被 EffectRef.params 覆写。`derivedElements = union(全部 effect 的 element)`，只读、缓存、不双写 |
| element → damageCategory | physical → physical；fire/ice/poison/lightning/mental/holy/dark → magic；none → none | 只读派生（编目映射表单点定义），服务 UI 分组与流派规约，不参与结算 |
| ResistanceSet 槽位 | 同元素八槽 | 逐元素一槽，走 sourceId 撤销；数值域见编队参数 |
| 元素谓词 | element_is | 判定效果元素，供状态触发与流派判定 |

元素闭集为八元素 + none。新风味一律走 tags（开放枚举，供规则增强与流派过滤）、显式状态或 unitType；需要抗性关系时复用现有槽，不新开元素。新增第 9 元素须同时满足：① 独立抗性槽 ② 独立状态触发 ③ 机制中心化且高频，否则折叠进现有枚举或改走 tag。element = poison 与中毒状态互不隐含，桥接一律走状态本体的触发表声明——是数据，不是代码。

## 三、效果条件谓词（EffectCondition）

> 36 个 kind 封闭集（33 谓词 + 3 组合子），schema `$defs/condition` 为机器权威。统一带参谓词族，不为每种比较新开 ID。比较运算符 cmp ∈ `>` / `>=` / `<` / `<=` / `==`。side 取值域：self / target / ally / enemy / both / all / attacker。

| 谓词 | 参数 | 语义 |
|---|---|---|
| has_status | side, id, cmp, n | 指定方是否持有某状态且层数满足比较 |
| has_category | side, categories | 指定方是否持有指定类别的状态 |
| has_status_tag | side, tag, cmp?, n? | 指定方持有的状态中带该 tag 的数量比较（tag 来自 StatusDef.tags，开放词汇） |
| has_equipped | side, slot?, id?, tag? | 指定方是否持有装备（按 EquipmentInstance 判定）；slot 缺省 = 任意槽（weapon/armor）；id 精确匹配装备 defId，tag 匹配 EquipmentDef.tags。缺省不点名具体装备 |
| hp_percent | side, cmp, n | 指定方生命百分比比较 |
| stat_compare | aUnit, bUnit, key, cmp | 两名单位指定属性相互比较；位格绝对值比较走 key:'rank' |
| rank_gap | aUnit, bUnit, cmp, n | 两名单位**位格之差**（a−b）与 n 比较——「差 ≥N」缺口语义，stat_compare 表达不了 |
| caster_has_summon | tag?, unitId? | 施法者是否持有在场召唤物；tag 匹配召唤单位 tags，unitId 匹配 unitDef 蓝本 id，二者可叠加 |
| caster_status_exists | id | 施法者是否持有指定状态 |
| zone_active | zoneId | 场上是否存在指定区域 |
| gauge_above | n | 行动条进度高于阈值 |
| gauge_rank | n | 目标行动条位次判定（n=1 即全场第 1、即将出手）；用于分支条件，不等价于选靶排序 sort:gauge_desc |
| dispelled_count | cmp, n, scope? | 驱散数量比较；scope 缺省 chain = 本次效果链刚驱散数，battle = 本场累计驱散数 |
| consumed_count | statusId, cmp, n | 本次效果链刚消耗的指定状态层数比较（consume 入账）；不等价于剩余层数 has_status |
| dead_count | side, cmp, n | 指定方已死亡单位数比较 |
| target_dead | — | **具体目标**已死；不等价于 dead_count（后者数某一方死者总数） |
| field_status_count | id, cmp, n | 全场（不分敌我）指定状态实例数比较 |
| hp_percent_compare | aSide, bSide, cmp | 两名单位生命**百分比**相互比较（与 stat_compare 绝对值比较互补） |
| gender_is | side, value | 指定方性别判定（male/female） |
| faction_is | side, value | 指定方阵营判定（相对施法者，ally/enemy） |
| phase_is | phases[] | board.phase 属于集合之一即成立；取值 midnight / dawn / day / dusk / night |
| luminance_compare | cmp, n | board.luminance 与阈值比较。⚠️ 相位与光照度档位不严格同构——「必须是某相位」一律走 phase_is，不用 luminance_compare 近似 |
| resource_compare | side, key, cmp, n, aggregate? | 单位 Pool 现值比较（Pool 键见效果参数 modify_resource.resource）；aggregate:'sum' = side 范围内全部单位该 Pool 求和后与 n 比较（side:'all' 即全场求和），缺省 = 单单位现值 |
| meter_compare | key, cmp, n | 战场量表比较（board 级共享量，无 side）：secrecy / order / fate_value / luminance |
| damage_source_is | sources[] | 本次伤害来源类别：behavior（行为伤害：攻击/技能/对撞/反击，进通用乘区）/ status（状态持续伤害，不进乘区） |
| tag_chain | tag, cmp, n | 施法者同标签连击计数比较：连续施放与上一张同 tag 计数 +1、断链归零 |
| recorded_has | side, statusId, id | 指定方持有的 statusId 状态实例 slots/params 中含键 id 即成立——数据槽键的存在性读法 |
| element_is | element | 本次效果元素判定 |
| target_has_tag | tag | 目标携带指定 tag |
| target_unit_type | type | 目标 unitType 匹配 |
| target_is_summoned | — | 目标是否为召唤物（有召唤者），不细分种类 |
| variant_is | variant | 当前生效的卡变体（card.variants 释放变体）匹配 |
| chance | p | 概率条件：p ∈ [0,1]，单次抽样，只用于非伤害维度，须登记（随机性治理 R1–R6）；落空/阻挡语义一律用 charges 次数型状态的确定性写法 |

### 组合子

| 组合子 | 参数 | 语义 |
|---|---|---|
| any_of | conditions[] | 任一子条件成立即成立（OR） |
| all_of | conditions[] | 全部子条件成立才成立（AND） |
| not | condition | 取反（单子条件） |

可任意嵌套（如 any_of 内嵌 all_of）。**组合子本身不抽样**：chance 作为子条件时仍受 R3 登记制与 R4 单次抽样约束，抽样只发生在被组合的叶子条件上。

## 四、候选池过滤器（unitFilter）

> 目标系统级过滤器，供「不可被选中」类排除与召唤落位共用。开放结构：布尔属性缺省即不约束；新增维度须先在本文件登记。

| 字段 | 取值 | 说明 |
|---|---|---|
| unitType / tags / unitId / element | string 或 string[] | 维度匹配过滤 |
| hasStatus / hasCategory | id 或 id[] / statusCategory 或数组 | 要求持有指定状态 / 指定类别状态 |
| hpPercent | {cmp, value} | 按生命百分比过滤 |
| casterHasSummon / isSummon / isOwnSummon / casterOwned / isAllyOrMirror / isPuppet | boolean | 召唤与归属维度 |
| dispelable | boolean | 只取可驱散状态 |
| adjacency | object | 相邻性过滤，配合 spread 表达相邻/溅射目标域 |
| rankBelowCaster / rankAboveCaster | boolean | 仅位格低于/高于施法者入选（位格压制）；判定基准见编队参数 |
| rankMax / rankMin | int | 位格绝对档区间（含界） |
| gender | any / male / female | 性别过滤（与 card.gender 同源） |
| corpse | boolean | true = 候选池改为未过期亡骸，绕过 anchor/scope 几何；正常选靶仍排除死者 |
| tier / count | string/int/object | 分层 / 计数过滤 |
| anyOf | unitFilter[] | 子过滤器析取 |
| direction | inbound / outbound / both | 不可选中排除方向：仅 inbound = 敌方不可选中；both = 双向；outbound = 不可选中全向排除 |
| effectCategories | buff / heal / guard / damage | 按效果类别分流，实现「不可被增益但可被伤害」类非对称排除 |
| scope | single / all | 排除强度两档：single（缺省）只挡指定型（mode:unit），AoE 不吃；all = 连 AoE 一并挡住的绝对封印。⚠️ 与目标系统的几何 scope 同名不同物 |
| weight | int（缺省 100） | 候选池加权：目标选择/召唤落位的倾向权重，与 modify_targetability 同出口 |

识破类机制为反向开关（忽略隐匿/不可选中 × 伤害乘区），与候选池过滤器同出口，不另立机制。
