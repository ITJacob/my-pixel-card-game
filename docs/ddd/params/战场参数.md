# 战场参数与取值域

> 战场上下文的枚举取值域与结构常量权威。卡面平衡锚点不进本册（随英雄迁移登记于 `编队参数.md`）。
> 空间结构（两路 × 4 格 = 16 格、index 0 对峙前线）权威在 `../contexts/战场上下文.md`，本册不重复登记。
> 字段级结构权威是 `docs/json/schema/skills.schema.json`；本册只收枚举取值域与规则语义。

## 一、枚举取值域

### 1.1 区域（Zone）

> 定义落点：ZoneDef 集中存放于各文件顶层 `zoneDefs` 池，不内联卡级。
> 区域模型为**持续地形**：按 duration 存续、按 trigger 定结算时机、按 interval 节流；不含进入/离开触发，不设使用次数。下列三值为封闭集。

| 字段 | 取值 | 说明 |
|---|---|---|
| ZoneDef.kind | hazard / blessing | 区域类型 |
| ZoneDef.trigger | on_occupy_tick / on_attack / summon_skill | 触发面；`on_occupy_tick` 的节流由 interval 定；`on_attack` 与 16 触发点同名同事件，口径见 `执行参数.md`「on_attack 事件口径」 |
| ZoneDef.interval | 正整数（tick） | `on_occupy_tick` 每 N tick 触发一次；缺省逐 tick |
| ZoneDef.affects | ally_of_owner / enemy_of_owner / any | Zone 载荷按阵营分派生效分支 |
| ZoneDef.valueBoost | `{ stat, mul }[]` | 区域内数值倍率：**作用面 = 区域所有者的己方单位**，与 affects 的效果面独立；单位站区内时 `stat × mul`，离开区域 / 区域到期 / 死亡即撤销；同 stat 多区域相乘。每 tick 以可回滚溯源重算，基础值取不含倍率的当前值 |
| ZoneDef.effects | EffectRef[] | 多条、逐条独立判定；整次触发对当前占用者集合结算一次 |

占格 / 有血量 / 可被攻击 → 召唤单位；纯坐标效果、不占格 → Zone。判别与放置、触发、到期口径见 `../contexts/战场上下文.md`。

### 1.2 界域（Domain）

| 字段 | 取值 | 说明 |
|---|---|---|
| DomainDef.tier | overlay / hero | 上层（打出压栈）/ 英雄域（开局常驻，规则冲突优先级最高）。base 基层由 CombatSetup 注入、不可驱散，属战场结构层，见 `../contexts/战场上下文.md` |
| DomainDef.dispelable | boolean | overlay / hero 按设计；base 恒 false |
| DomainDef.durationUnit | turn / tick | — |
| DomainDef.triggers | TriggerDef[] | 走全局监听通道，挂 on_tick / on_turn_start 等触发点结算载荷 |
| DomainGrant.duration | 正整数（tick）/ -1 | -1 = 常驻；被压制的上层界域 duration 暂停递减 |
| DomainGrant.priority | 整数 | 上层栈排序键，按打出序号递增，后打出者压顶 |

**RulePatch（规则改写补丁）**：`DomainDef.rulePatches` 是声明式规则改写，由流水线既定节点被动读取，不引入新节点、不直接改状态。`kind` 为封闭四值：

| kind | 字段 | 读取节点 | 说明 |
|---|---|---|---|
| seal_effect | effectType | I 候选池 | 禁用指定效果类型 |
| disable_effect | side / effectType 或 tag | I 节点 | 指定阵营的指定类型或标签效果失效；effectType 可取 `shield`（受击方护盾段不吸收伤害，由伤害链读取） |
| cost_mod | effectType 或 tag / delta | commit 成本校验 | 指定类型或标签技能的能量成本增减；delta = 1 表示费用 +1 |
| empower | side / stat / mul / tag? | O 节点 | 指定阵营的属性或伤害乘区，可按标签过滤 |

公共过滤字段：`tag`（any-of，取自 `SkillDef.tags`）/ `tagNot`（none-of）/ `singleTarget`（仅单体技能，即 `targetSpec.request.mode !== area` 且 pickCount 缺省或 1）。`side` 取值 all / ally / enemy / both——disable_effect 与 empower 必填；seal_effect 与 cost_mod 天然敌我双向，不写本字段。

纪律：新 kind 必须绑定既有节点，不得新增流水线节点、不得直接改写状态。周期性战场效果不走补丁，走 `DomainDef.triggers`（战场级触发器 + EffectRef 载荷）。界域 × 卡标签的交互统一走带 tag 过滤的补丁。

### 1.3 战场时钟（BattleClock）

战场级时间轴：**1 tick = 20 叙事分钟，一天 72 tick**。时钟只进不退，`board.clock` 每 tick +1，到 71 后归 0。本节的 72 tick 是叙事时钟周期，与 `../params/执行参数.md` 的「1 回合 = 5 tick」行动周期分属两套单位，**不得互相换算**。

| 字段 | 取值 | 归属 | 说明 |
|---|---|---|---|
| board.clock | int[0,71] | 战场（唯一可写源） | 起始值在 CombatSetup 确定 |
| board.luminance | int[0,10] | 战场（只读派生） | 由 clock 查 §1.3b 表得出，不双写 |
| board.phase | midnight / dawn / day / dusk / night | 战场（只读派生） | 同由 clock 查表得出 |
| board.lumOverride | `{ value, duration, sourceId }` | 战场（覆写层） | 优先级高于派生值；按打出序号压栈，到期回落到 clock 派生值 |

`set_luminance` 写入 `board.lumOverride`：绝对档位 `value` 或相对增量 `delta`，二者互斥；相对模式按施加瞬间的生效值（clock 派生值或覆写栈顶）计算并 `clamp(生效值 + delta, 0, 10)` 后压栈。覆写写入与自然跨相位边界同等派发 `on_phase_change`。`advance_clock` 只做 `board.clock += N (mod 72)`，不提供回拨算子；「回到过去」走快照回滚，非逆转时光。

**档位与相位不严格同构**：黎明前段（tick 12–15）光照度 ≤2，落在暗夜档，会让黎明轴效果在此窗口吃到暗夜档乘区。需要精确判定的效果一律走 `phase_is` 谓词，不用 `luminance_compare` 近似。

**月夜**：不单列相位，定义为 `phase ∈ {night, midnight}` ∧ 月相可见条件成立，不新增量表。
