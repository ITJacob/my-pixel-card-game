# 效果参数

> 32 原语的参数取值域（封闭集）。权威列表以 `docs/json/schema/skills.schema.json` 的 `effect.oneOf` 为准；新增原语须先登记 `docs/meta/SCHEMA.md` §5 封闭集清单与本表。

| 原语 | 关键参数 | 说明 |
|---|---|---|
| damage | value / element / pierce / spread / lethal / dot | 走伤害链；数值零随机 |
| heal | value / mode | delta / setHp / hpMaxRatio / to_ratio |
| mount_status | statusId / duration / stacks / charges | 施加状态实例 |
| modify_stat | stat / value / mode / duration | delta/set/mul/to_at_least/to_at_most；不可驱散 |
| modify_resource | resource / value / mode | delta/set/swap；护甲修正走装备强化规则 |
| move | op / distance | 占位变更（7 种 op）；击退走行动条数值 |
| spawn | unitDef / position / count / summonCap | 一卡一单位；超限最老消散 |
| dispel | target / filter | unit（按类别/可驱散/数量）/ coordinate（拆陷阱）/ domain（解上层） |
| drain | resource / ratio / healRatio | 伤害按比例回复 |
| domain | op / defId / duration | overlay（压栈）/ swap（置换底层）/ hero（英雄域） |
| translocate | op / duration / payload | pull_into（拉回）/ banish（放逐，可带回归载荷） |
| snapshot / restore_snapshot | scope / snapshotId | 快照字段子集；只恢复声明范围 |
| modify_damage | scope / mode / value | 一次性改本次伤害（区别于状态乘区） |
| target_override | faction / anchor / sort | 改写本次选靶请求 |
| transfer_status | to / mode | copy / rewrite |
| echo_last_skill | potency | 按比例重放上一技能 |
| gauge_shuffle / status_shuffle | resource / mode | 数值守恒重排 / 状态轮转 |
| modify_skill | 清CD/改费用/改吟唱/改写TargetSpec | 行为层修改 |
| modify_status | statusId / addDuration / setDuration / chargesDelta… | 改写已存在实例 |
| modify_targetability | direction / pierce | 可锁定性 |
| reveal | scope | 显形（区别于 dispel 隐匿类别） |
| grant_immunity | against / duration / charges | 免疫类别/元素 |
| take_control | duration / onExpire / actionPolicy | 夺控到期还原/死亡/保留 |
| write_rule_slot / modify_rule_slot | slot / field / mode | 规则槽写入/改写 |
| set_luminance | value / duration | 光照度覆写压栈 |
| advance_clock | ticks | 时钟推进，触发相位 |
| disarm | slot（weapon/armor） | 卸下并摧毁装备，触发同槽公用 CD |
| modify_weapon | restoreDurability / durabilityDelta / attackDelta | 武器槽专用 |
| recover_equipment | slot / cooldownMul（缺省 0.3） | 主动回收，不占机会由 cost.opportunity:0 表达 |

## 通用参数

- **element**：纯标签无内建数值语义；伤害类必填。
- **mode 族**：delta（默认）/ set / mul / swap / to_at_least / to_at_most。
- **duration**：tick（默认，墙钟）/ self_turn（持有者自身机会数）。
- **条件采样**：`{kind:'chance', p}` 只用于非伤害维度；落空用 charges。
