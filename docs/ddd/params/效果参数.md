# 效果参数

## 动态取值（valueFrom）

> 效果数值可在结算期读取运行态得出。**只读、不产生副作用**；字段结构以 `skills.schema.json` 为准，本节规定取值域、求值时机与边界。新增来源须绑定既有求值节点，不得新开流水线节点。

| 形态 | 写法 | 读取对象 |
|---|---|---|
| 战场标量（string 简写） | `valueFrom: "order"` | 战场量表现值；键取值域同 `共享内核参数.md` §三 meter_compare.key |
| 计数型简写 | `valueFrom: "death_ledger"` | 按 statusId 读目标持有层数的账本类读数 |
| 状态递进档位 | `{kind:'ramp'}` | 状态实例自带的 ramp 数组，按该触发器在本实例上的 fire 序号取值；超出长度取末值 |
| 目标属性 | `{kind:'target_stat', stat}` | 当前结算目标的属性现值；stat 取值域以 schema 为准 |
| 状态层数公式 | `{statusStacks, formula}` | 指定状态的在场层数代入公式求值 |
| 参照源（独立字段） | `sourceRef: caster / secondary_target / field_average` | 改变取值所参照的单位，不改变取值域 |

**对象形态封闭集**（`valueFrom` 为对象时只允许下列三形态；机器侧 `$defs/valueFrom` 为权威，由 `check_enum_sync` 对账）：

| kind | 判别 | 必需字段 |
|---|---|---|
| ramp | `kind` 常量 | kind |
| target_stat | `kind` 常量 | kind / stat |
| formula | 数据侧无显式 kind 字段，由必填字段判别 | statusStacks / formula |

string 简写两族：战场量表键（取值域同 `共享内核参数.md` §三 meter_compare.key）与账本类 statusId。两族都必须在编目期可解析，非法键由门禁拦截，不留给运行期兜底。

**求值时机**：O 节点逐效果、逐目标求值——I 节点冻结的是 committedTargets，不是数值。群攻时同一效果对每个目标各自求值，不得在 I 节点算一次后跨目标复用（INV-24）。

**value 与 valueFrom 的关系**：`value` 是基线数（缺省 0）。除公式形态外，最终值 = 读数 + value；公式形态下 `formula` 给出完整表达式并覆盖 value，value 仅作编目期兜底。`describe` 必须写出取值来源，不得只报常量（`编目参数.md` 文案同步）。

**边界**：

- 读数只读取，不改写状态 / 账本 / 量表；条件谓词的只读纪律同样适用。
- 目标死亡 / 离场 / 引用不存在时，依赖该目标的读数无值 → 按 `../contexts/战斗上下文.md` §目标中途失效 的统一判据跳过该 (效果, 目标) 对，不回退为常量、不抛异常。本节只规定读数侧边界，不另立失效判据。
- 公式只允许四则运算、括号与 `stacks` 变量，禁止函数调用与副作用；编目期校验语法与 `statusStacks` 引用完整性。
- 结果按原语合法域钳制（伤害不为负、层数取整等），钳制不改变只读性质。
- 失败态：在 I 节点提前求值 → 群攻跨目标串值；读数静默回退常量 → 卡面与实参脱节；公式求值失败被吞 → 后果不可归因。

## 通用参数

- **element**：纯标签无内建数值语义；伤害类必填。
- **mode 族**：delta（默认）/ set / mul / swap / to_at_least / to_at_most。
- **duration**：tick（默认，墙钟）/ self_turn（持有者自身机会数）。
- **条件采样**：`{kind:'chance', p}` 只用于非伤害维度；落空用 charges。
