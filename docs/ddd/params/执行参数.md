# 执行参数

> 16 触发点封闭集（INV-18）+ 计时口径。

## 触发点（passive_hook / trigger.event 同域）

| 触发点 | 时机 | 语义要点 |
|---|---|---|
| on_battle_start | 战斗开始 | 开局装备/快照类 |
| on_turn_start | 获得行动机会 | 机会括号左端 |
| on_turn_end | 机会结束 | 机会括号右端；wasted 也闭合 |
| on_apply | 状态挂载时 | 挂载即 fire |
| on_remove | 状态卸载时 | 可按原因过滤（expired/dispel/consumed/overwritten）；配合溯源撤销 |
| on_tick | 每 tick | 高频钩子用 minIntervalTicks 节流 |
| on_phase_change | 相位变更 | 时钟跨边界或光照度覆写写入时 |
| on_spawn | 单位落场 | 含召唤物登场 |
| on_death | 单位死亡 | 死亡链入口 |
| on_kill | 击杀 | 击杀归因 |
| on_attack | 攻击行为 | 普攻/攻击类主动；会消耗武器耐久的语境 |
| on_equipment_equip | 装备牌装备时 | 实例建立后、战吼前 |
| on_active_skill | 主动技能施放时 | — |
| on_take_damage / on_deal_damage | 承伤/出伤 | 伤害链结算前后语境 |
| on_status_gain | 获得状态时 | 语义层强制登记制 |

## 载体规则

触发器只挂在持续存在的主体上：状态 StatusDef.triggers、被动 BehaviorTemplate、装备 equipment.triggers、召唤物 unitDef.triggers、界域 DomainDef.triggers。
**主动/召唤卡的顶层 triggers 不是合法载体**（一次行为没有持续监听语义）：瞬时后果写效果树 `if`，持续监听写入状态/装备/召唤物蓝本。

## 计时口径

| 字段 | 取值 | 说明 |
|---|---|---|
| durationUnit | tick / self_turn | tick = 墙钟递减；self_turn = 持有者自身行动机会数（机会括号左端扣 1） |
| duration | 正整数 / null | null = 常驻（Def 层声明）；0 = 一次性 |
| charges | 正整数 | 响应式派发 −1，归零卸载 |

## 触发器节流

- minIntervalTicks：同一触发器实例每 N tick 至多 fire 一次。
- maxTriggersPerBattle / oncePerBattle：每场限次。
