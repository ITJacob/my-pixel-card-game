# 执行参数

> 16 触发点封闭集（INV-18）+ 计时口径。

## 触发点（passive_hook / trigger.event 同域）

| 触发点 | 时机 | 语义要点 |
|---|---|---|
| on_battle_start | 战斗开始 | 开局装备/快照类 |
| on_turn_start | 获得行动机会 | 机会括号左端 |
| on_turn_end | 机会结束 | 机会括号右端；wasted 也闭合 |
| on_apply | 状态挂载时 | 挂载即 fire |
| on_remove | 状态卸载时 | 可按原因过滤（expired/dispel/consumed/overwritten）；配合溯源撤销 |
| on_tick | 每 tick | 高频钩子用 minIntervalTicks 节流 |
| on_phase_change | 相位变更 | 时钟跨边界或光照度覆写写入时 |
| on_spawn | 单位落场 | 含召唤物登场 |
| on_death | 单位死亡 | 死亡链入口 |
| on_kill | 击杀 | 击杀归因 |
| on_attack | 攻击行为 | 普攻/攻击类主动；会消耗武器耐久的语境 |
| on_equipment_equip | 装备牌装备时 | 实例建立后、战吼前 |
| on_active_skill | 主动技能施放时 | — |
| on_take_damage / on_deal_damage | 承伤/出伤 | 伤害链结算前后语境 |
| on_status_gain | 获得状态时 | 语义层强制登记制 |

## 载体规则

触发器只挂在持续存在的主体上：状态 StatusDef.triggers、被动 BehaviorTemplate、装备 equipment.triggers、召唤物 unitDef.triggers、界域 DomainDef.triggers。
**主动/召唤卡的顶层 triggers 不是合法载体**（一次行为没有持续监听语义）：瞬时后果写效果树 `if`，持续监听写入状态/装备/召唤物蓝本。

## 计时口径

| 字段 | 取值 | 说明 |
|---|---|---|
| durationUnit | tick / self_turn | tick = 墙钟递减；self_turn = 持有者自身行动机会数（机会括号左端扣 1） |
| duration | 正整数 / null | null = 常驻（Def 层声明）；0 = 一次性 |
| charges | 正整数 | 响应式派发 −1，归零卸载 |

## 触发器节流

- minIntervalTicks：同一触发器实例每 N tick 至多 fire 一次。
- maxTriggersPerBattle / oncePerBattle：每场限次。

## 调度（tick 推进与机会授予）

### tick 原子步

1. 时钟前进；2. 全部 Gauge.advance；3. Pool 按 regen 恢复；4. Channel.remaining--；5. Cooldown.remaining--；6. 状态与溯源账本时限条目 remaining--（到期回滚）；7. Zone 与 active 界域 duration 递减（被压制的上层界域不计时）；8. 收集本 tick 全部越阈 → 先手排序 → 依次授予机会。推进（1–7）与授予（8）严格分离；detached 单位不参与 2–6，回归后原样续走。

### 取值域

| 字段 | 取值 | 说明 |
|---|---|---|
| Gauge 触发条件 | 严格越过阈值（>，非 ≥） | 资格判定发生在跨过阈值的那 tick |
| overflowPolicy | Keep（越界留存） | 预留 Reset |
| 先手交替模式 | [己,敌,敌,己] 循环 | 双方各自排序后交替合并，禁止按位置分层 |
| 冷却起点 | 提交时刻 | 引导期与冷却重叠 |
| 打断 | 资源不退 | 提交即承诺 |
| 行动周期 | 派生值 = threshold / rate | 禁止被 modify_stat 直接修正 |

### 数值基准

精力阈值 75（Gauge.threshold 与 cost.gaugeAmount 缺省，二者默认相等故默认行为不变）。cost.opportunity = 1（正常消耗机会）；0 = 本次 Action 不闭合机会，同一机会内免费 Action 至多 2 次（防无消耗循环），仍扣能量/冷却。

### 〇点五、回合 ↔ tick 换算基准

**1 回合 = 5 tick**（基准行动周期 = 75 / (15 + 8×敏捷)，敏捷 0 恰为 5 tick）。全部 duration 字段一律 **tick 存储**落库（durationUnit 只有 tick / self_turn 两值）；稿期「N 回合」口径按本基准换算，禁止把回合数 1:1 抄成 tick。self_turn 按持有者自身机会数递减：每次获得机会扣 1，与墙钟脱钩，detached 期间冻结；高敏捷单位行动周期 < 5 tick，「每回合触发」类效果自然更密（敏捷红利，不补偿）。modify_status 加时按目标状态自身的 durationUnit 口径填值（对 self_turn 状态填 2 = 加 2 个自身回合）。
