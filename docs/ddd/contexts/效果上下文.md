# 效果上下文

> 效果树 = 原语（叶子）+ 算子（结构）。**原语 32 个封闭集**（INV-17），权威列表以 `docs/json/schema/skills.schema.json` 的 `effect.oneOf` 为准。

## 原语分族

| 族 | 原语 | 一句话 |
|---|---|---|
| 伤害/治疗 | damage / heal / drain | 伤害走伤害链；治疗一律走 heal 不混资源修正；drain 伤害按比例回复 |
| 状态 | mount_status / dispel / transfer_status / modify_status | 施加/移除/搬运/改写状态实例 |
| 属性/资源 | modify_stat / modify_resource | 无宿主修正（不可驱散）/ 资源池增减；护甲修正走装备强化规则 |
| 位移/位置 | move / translocate | 占位变更；translocate 离场-回归，不持坐标 |
| 召唤 | spawn | 引用 unitDef 蓝本落场；复活走 reviveOf |
| 装备 | disarm / modify_weapon / recover_equipment | 缴械 / 武器槽改写 / 主动回收装备（CD 缩减） |
| 选靶/信息 | reveal / modify_targetability / target_override | 显形 / 可锁定性 / 改写本次选靶 |
| 技能/状态重排 | modify_skill / modify_status / echo_last_skill / gauge_shuffle / status_shuffle | 行为层改写 / 回响上一技能 / 守恒重排 |
| 界域/区域 | domain / snapshot / restore_snapshot | 界域三操作（叠加/置换/英雄域）/ 快照回滚 |
| 控制 | take_control / grant_immunity | 夺控（到期还原/死亡/保留）/ 免疫授予 |
| 规则 | write_rule_slot / modify_rule_slot | 写入/改写战场规则槽 |
| 环境 | set_luminance / advance_clock | 光照度覆写 / 时钟推进（触发相位） |

## 算子（3 个，结构无结算语义）

- `sequence`：顺序执行（编目期展开为扁平序列）
- `repeat`：按次数重复（次数可运行期计算）
- `if`：条件分支（condition 走谓词封闭集）

## 边界裁定

- **disarm vs dispel**：装备是 EquipmentInstance 不是状态；dispel 只清 StatusInstance；卸下装备走 disarm / recover_equipment / 下线条件。
- **translocate 为何独立**：move 的语义绑定坐标与占位；translocate 的单位离场后不持坐标，强塞进 move 会污染驱散边界。
- **domain 为何独立**：mount_status 必须有宿主单位，界域是战场级无宿主实体。
- **modify_damage vs 状态乘区**：modify_damage 一次性改本次伤害；状态持续乘区是另一回事（伤害链⑤段）。
- **几率**：概率只能写成条件采样节点（R1–R6），原语本身不含随机。

## 条件谓词（封闭集，取值见 params/共享内核参数）

持有状态/状态层数/资源比较/属性比较/装备持有（has_equipped）/量表比较（meter_compare）/已记录参数存在性（recorded_has）/已消散计数（dispelled_count/dead_count）等。谓词只读，不产生副作用。
