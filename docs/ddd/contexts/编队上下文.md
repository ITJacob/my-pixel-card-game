# 编队上下文

> 单位 = 属性 + 资源池 + 技能槽 + 装备槽 + 状态集；战斗内实体统一由 Registry 寻址。

## 单位属性

力量 / 敏捷 / 智力 / 位格（rank）四项基础属性。有效攻防 = 基础 + 修正（溯源账本）；只改源属性，不改派生值（行动周期是派生值）。

## 溯源账本 StatProvenance（INV-27）

属性与抗性修正的一等记账实体，记录「每项修正来自谁」：sourceId = 状态/装备/效果**实例** id（实例级非类型级），每个 sourceId 在单位上全局唯一，同种状态的两个实例各自记账、各自撤销。每项修正记 (stat, oldValue, sourceId)；时限修正自带 remaining，由 tick 递减、到期自动撤销。

| 操作 | 说明 |
|---|---|
| apply / applyTimed | 写入永久 / 带时限修正，返回句柄 |
| revertBySource | 按来源回滚全部条目（状态到期/驱散/光环移除/时限耗尽时调用） |
| revertAll | 清空全部修正（单位离场必须调用） |
| entriesOf | 审计视图：某项属性的全部修正来源 |

三条纪律：撤销 = **恢复到该来源写入前的值**，不是减去写入量；账本条目与修正集合一一对应，不存在无主修正；离场不清理会泄漏到对象复用。抗性逐元素开槽，与属性走同一套账本、同一种可撤销写入。

## 资源模型：Gauge 与 Pool

| 维度 | Gauge（进度条） | Pool（资源池） |
|---|---|---|
| 语义 | 累积到阈值触发一件事（「资格」来源） | 可增减的量（「成本/状态」载体） |
| 字段 | current / rate / threshold / overflowPolicy | current / min / max / regen |
| 变更后果 | 越阈发事件 + 按策略扣减 | 数值变化；触底/触顶可发事件（死亡） |

Gauge 每 tick `current += rate`，**严格越过阈值（>）**才发越阈事件、按 overflowPolicy 扣减（Keep = 留存越界部分）——资格判定发生在跨过阈值的那 tick。行动周期 = threshold / rate 是派生值，只经 rate/threshold 正当修正。

## 技能槽与行为槽

- **主动槽**：装主动/装备/召唤卡（统一竞争牌位）；每卡是一个行为槽实例，带独立冷却。
- **被动槽**：装被动卡（触发钩子 + 持续修正）。
- 普攻与移动都是**特殊行为槽**（不占卡位、0 能量、消耗行动机会）；移动落点规则见战场上下文「默认主动移动」。攻击类主动技能默认不消耗武器耐久（「会消耗耐久的攻击」= 普攻语境）。

## 装备两槽（INV-8/9/10/12）

| 槽 | 模型 | 下线条件 |
|---|---|---|
| 武器 | 攻击加值（溯源修正）+ 耐久 | 耐久按普攻次数消耗，归零下线 |
| 护具 | 护甲池（容量水位 = 初始值） | 池空下线；卸下清零 |

- 打出装备牌 → 同槽旧件下线 → 建实例 → fire on_equipment_equip（先于战吼）→ 战吼。
- 下线路径：耐久归零 / 护甲池空 / 缴械 / 主动回收 / 同槽顶替。下线那一刻同槽公用 CD 才开始计（INV-12）。
- 装备强化：护具池正值充池并抬容量水位；无护具时护甲类修正改充护盾（护盾逻辑不变）；负值只削护甲池。
- 缴械（disarm）卸下并摧毁指定槽装备；装备不是状态，dispel 不作用；无背包。

## 状态机

- 状态 = StatusDef（蓝本）→ StatusGrant（值对象）→ StatusInstance（战斗内实体）。
- 类别只有 buff / debuff 二元（INV-16）；control/stance/conceal 等是机制标签。
- 生命周期：挂载（去重/叠层/刷新策略）→ 计时（tick 或持有者自身机会数 `durationUnit`）→ 卸载（到期/驱散/消耗/overwritten）→ 溯源回滚。
- 次数型状态（charges）：每响应式派发 −1，归零卸载；落空/阻挡语义用 charges 表达。
- 驱散边界（INV-5）：dispel 只清 StatusInstance；modify 类属性修正不可驱散。
- 硬控命中清除姿态（stance）类状态；单位自身回合跳过不消耗姿态时长；采取非跳过行动时先退出姿态再行动。
- 身份状态单一主责：一个身份状态只由一张卡承担主授予。

## 吟唱与冷却

- **Channel**：castTime > 0 的行为提交后进 Channeling——目标已在点火时解析并冻结，remaining 逐 tick 递减，归零结算挂起效果。引导期可被带 interrupt 标志的硬控打断：效果作废、**资源不退**（提交即承诺）。cast_time_set 修正聚合取最小（0 = 免吟唱）。
- **Cooldown**：从提交时刻起算（引导期与冷却重叠），逐 tick 递减。

## Unit 状态机与死亡结算链

spawn → Active ⇄ Channeling（引导开始/结束）；生命触底 → Dying → 死亡结算链 → Removed（revertAll + Placement.remove，见战场上下文）。

生命触底进入 Dying 时按优先级逐项判定，命中即短路、不再向下（INV-28）：

1. `revive_blocked` → 禁止任何复活（含替身压制），直接走死亡结算；
2. `defined_substitute` → 替身/替死实体接管死亡，本体不入死亡流程；
3. `lethal_protect` → 阻止致死，生命钳制在 1（不进 Dying、不触发 on_death）；
4. `on_death` 链 → 触发 on_death 亡语；载荷含复活则复活，否则离场入亡者寻址（见下）。

lethal_protect 与 dot_cannot_kill 共用一个死亡插桩（any / dot 区分任意致死 / 仅持续伤害致死）；damage_cap 是独立的单次伤害截断，不阻止死亡。姿态面：近战同步对撞已基础化（不再要求决斗姿态，该姿态已移除，见战斗上下文「近战同步对撞」）；反击姿态 = 远程顺序回击（先挨打再还手，charges 基准 2）；守卫姿态 = 拦截投掷。

## 召唤

- 召唤牌打出即落场，引用 unitDef 蓝本（一卡一单位）。
- 召唤位上限（INV-13）：基数 + 加成/覆写取高；超限 = 最早在场者消散（不走死亡链、不计死亡簿）。
- 维持费型特权：以每 tick 资源供给换额外召唤位，断供即收敛。

## 亡者寻址

- 阵亡单位进入亡者寻址表（短期，3 tick），可被「复活/唤起」类效果寻址；到期消散只发过期事件。
- 复活不重置溯源（临时修正保留，由卡面自行清理）。

## 变身/形态

- 形态组（formGroup）互斥轮转；形态绑定状态与属性改写走标准挂载/回滚，不特设机制。
