# 战场上下文

> 战场级实体：界域（Domain）、区域（Zone）、规则槽（Rules[3]）、时钟/相位、光照度、量表。

## 空间结构

Coordinate = (faction, lane, index) 三元组，全局唯一、结构稳定的值对象，是战场上一切寻址的依据；Slot 持有 occupant（空 = null）；Lane 是定长线性队列，index 0 永远是对峙前线；Faction 持有若干 Lane；Battle 是空间容器，持有全部 faction 与挂载的 zones。占格 / 有血量 / 可被攻击 → 召唤单位；纯坐标效果、不占格 → Zone。

## Placement：唯一占位出口（INV-21）

所有占位变更只经 Placement——它是唯一有权写 `Slot.occupant` 与单位 position 投影的组件，任何模块不得直接写坐标。每个操作走统一模板：快照 → 执行变更 → 坍缩 → 刷新投影 → 不变量校验（失败回滚快照）→ 发 OccupancyChanged（占用 diff）。

| 操作 | 前置 | 行为 |
|---|---|---|
| insert / remove / swap | 容量与在场校验 | 写槽 → 坍缩 → 刷新投影 → 发事件 |
| relocate | 目标路未满；**不得跨阵营** | 原位置空、新位置写，双端坍缩 |
| applyExternal | — | 快照 → mutator → 校验门禁，失败回滚 |

- OccupancyChanged 是 Zone 触发的**唯一入口**——Zone 监听「占用关系变化」这一事实而非「移动」动作：击退、召唤、死亡补位、换路全部自动获得区域触发。

## 默认主动移动（基础行为，与普攻并列）

单位自带的移动行为壳（schema 行为封锁 `move` 类），统一**插入语义**——移动 = 将自身插入目标位置的队列，原位置起后缀顺移补位；**目标路已满（到容量上限）则插入被拒**，无交换、无挤占（2026-11-01 口径：基础移动与时隙移动同理）：

- **同路插入**：插入同路相邻位（前/后一格）。
- **换路插入**：`relocate` 插入另一路（**不得跨阵营**，不得越中线）；目标路已满则换路被拒。
- **不是全场随意插入**：不得借 `absolute` / `fixedIndex` 指定任意坐标——基础移动落点集由插入前置自然限定（时隙派系基准不受此限，可插入任意路任意位，但**满则拒同样适用**）。
- 技能位移不受此限：`move` 原语（推退系、translocate 等）满足前置（同阵营、容量、G8）即可落任意合法坐标。

## Collapse 坍缩（INV-22）

占位变更后队列必须**在同一原子步内**坍缩为前缀紧凑：非空 occupant 保持相对顺序、从 index 0 依次填回，其余置 null。幂等（对已紧凑队列无效果）、保序。占用恒为 {0,…,k−1} 前缀、无内部空洞——这是转向、先手等跨单位规则正确性的前提。

## 界域（Domain）与压制栈（INV-14）

- 界域 = DomainDef → Grant → Instance 三件套；**战场级、无宿主**。tier 三层：base（CombatSetup 注入，不可驱散，仅 swap 可置换）/ hero（英雄级，常驻，规则冲突优先级最高）/ overlay（卡牌打出，压制栈）。
- 三个操作：`overlay`（压栈，原栈顶转压制）/ `swap`（置换底层，唯一改写底层的出口；仅改层籍不删实例）/ `hero`（开局挂载）。
- 覆盖规则：同一时刻仅栈顶 active；被压制者不删除、不结算任何规则、duration 暂停递减；栈顶解除后下层剩余时长恢复生效。消亡：duration 耗尽，或被 dispel（仅 dispelable 且非 base）。
- 界域可携带：维度乘区（empower/disable）、租金（持续资源消耗）、规则补丁（rulePatches，压栈时注入战场规则）、战场级触发器（triggers，走全局监听通道，挂 on_tick / on_turn_start 等触发点结算载荷）。
- RulePatch 是声明式规则改写：由流水线既定节点（I 候选池 / commit 成本校验 / O 节点）**被动读取**，不引入新节点、不直接改状态。

## 规则槽 Rules[3]（INV-15）

- 战场级定长 3 槽；每槽 = trigger（触发条件）+ punishment（违约惩罚）+ exemptions（豁免名单）+ scope。
- 写入走 write_rule_slot（空槽才写/覆写）；改写走 modify_rule_slot（replace/append/remove）。
- 违约判定由战斗事件流驱动：命中 trigger 且不在豁免名单 → 执行 punishment。
- 规则对双方生效；豁免是资源/状态购买的特权。

## 区域（Zone）

- 坐标级占位实体（陷阱/地形），以坐标为唯一键，触发条件 + 使用次数（charges 确定性写法，不用概率）；可被 dispel（coordinate 目标 = 拆陷阱）。
- **放置**：zone 类 consumption 在 M 节点注册，落点不依赖任何 UnitId；triggerOnExisting = true 时先结算在场者（缺省不触发）。纯伤害/减益类可跨中线落敌方半场；含位移/生成载荷的恒落己方半场。
- **触发**：用 before/after 两张战场快照 diff 判定「进入」——坍缩落入、同坐标换人（A 死 B 补位）都算进入；逐条执行 ZoneGrant.effects（各带 condition），整次触发只耗一次 uses。
- **到期**：duration 耗尽 / uses 耗尽 / 被显式移除 → 消散。

## 时钟 / 相位 / 光照度

- 战场时钟按 tick 推进（mod 周期），自然跨相位边界派发 on_phase_change。
- 相位（昼/夜…）是维度乘区与触发的读取面；光照度（luminance）是独立量表，可被覆写（压栈、到期回落派生值）。
- set_luminance 写入覆写层与自然跨边界同等派发相位触发。

## 战场量表

| 量表 | 值域 | 写入面 |
|---|---|---|
| secrecy 隐秘 | [0,10] | 登记途径（星象/潜行类） |
| order 秩序 | [0,10] | 登记途径（规则/混乱类） |
| fate_value 命运 | [-10,10] | 登记途径（命运类） |
| luminance 光照度 | [0,10] | 界域与光照类效果 |

量表是**共享通道**：推高/压低构成派系间的环境争夺（负向联动的正当载体）。
