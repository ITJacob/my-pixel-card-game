# 战斗上下文

> 整场战斗一聚合（INV-1）；进度条回合制、无手牌（INV-6）。

## 回合模型：行动条（gauge）进度制

- 时间以 **tick** 推进；每个单位有行动条，每 tick 按速率增长，**越阈即获得一次行动机会**（opportunity）。
- 速率与阈值是源属性；「行动周期」是派生值（= 阈值 / 速率）。改速率或阈值就是改周期的正当方式。
- **机会括号**（INV-7）：机会获得（on_turn_start）与机会结束（on_turn_end）都 fire 触发器；即使机会被跳过/作废（wasted）也闭合。按「谁获得行动机会」fire，不是按阵营轮替。
- 单位采取行动的**同一机会内可连续行为**，直到无可用行为或主动结束（cost.opportunity 标记行为是否消耗机会）。

## 行为可用性过滤（固定顺序，结果确定）

1. 卡槽冷却中 → 不可用
2. 装备牌：其装备实例仍在线 → 不可重打（防自我顶替刷新）
3. 强制行为白名单（force 类状态）→ 只放行名单内行为
4. 吟唱/引导中 → 不可用（可打断）
5. 能量不足以支付费用 → 不可用
6. 行动条不足以支付费用 → 不可用

## 伤害链（有序减伤管道，阶段固定）

一次伤害按固定阶段顺序结算，配置决定组成、顺序不可重排：

1. **护盾段**（LIFO）：护盾池吸收任意元素的非 DoT 伤害
2. **护甲段**：只抵消有形伤害——无形元素（精神/圣神/黑暗）与 DoT 绕过（INV-11）；支持比例破甲
3. **抗性段**：元素抗性乘性，钳制 [-50%, +75%]
4. **防御段**：防御线性减法
5. **乘区段**：状态持续乘区（增伤/减伤/易伤）、维度乘区（dimHooks）、界域 empower 乘区（DoT 不进本段）

旁路规则：DoT 只过抗性段与乘区段（跳过护盾/护甲/防御）；lethal（直连死亡）跳过全部减伤。

## 资源池（单位级）

| 池 | 说明 |
|---|---|
| hp | 生命；上限独立属性 |
| energy | 能量；行为费用货币，每 tick 回复 |
| shield | 护盾；伤害链第一段吸收；无装备依赖 |
| armor | 护甲；只源于当前护具（INV-11）；强化规则见编队上下文 |
| lost | 迷失值；只增不减，阈值档惩罚（档位载荷随英雄迁移登记） |
| lust | 恶欲值；可增可减（通道玩法） |

战场级量表（secrecy / order / fate_value）归战场上下文。

## 元素与抗性

- 元素是**纯标签**（无内建数值语义）；伤害类必填，其余填 none。
- 抗性槽按元素开设（火/冰/毒/雷/精神/物理/圣神/黑暗 + 全元素通配）；抗性只影响伤害链③段。

## 目标选择

- 选靶分两步：射程（reach，近战/远程…）+ 选靶请求（faction/anchor/sort/pickCount）。二者正交（INV-20）。
- 候选池过滤（单位类型/标签/状态持有/血量百分比等）是选靶请求的过滤面，不改变 anchor 语义。
- 必然命中（neverMiss）与隐匿/不可锁定（conceal 类别 + see_through 识破）是候选池与命中层的反制成对概念。
