# 战斗上下文

> 整场战斗一聚合（INV-1）；进度条回合制、无手牌（INV-6）。

## 回合模型：行动条（gauge）进度制

- 时间以 **tick** 推进；每个单位有行动条，每 tick 按速率增长，**越阈即获得一次行动机会**（opportunity）。
- 速率与阈值是源属性；「行动周期」是派生值（= 阈值 / 速率）。改速率或阈值就是改周期的正当方式。
- **机会括号**（INV-7）：机会获得（on_turn_start）与机会结束（on_turn_end）都 fire 触发器；即使机会被跳过/作废（wasted）也闭合。按「谁获得行动机会」fire，不是按阵营轮替。
- **同 tick 每单位至多一次机会**（INV-26）；机会未被消耗（无可用行为 / 跳过）记为 wasted，不累积到下一 tick。
- **先手次序**（INV-25）：双方各自按战场位置排序后**交替合并**（既定交替模式），不按战场位置分层合并。
- tick 原子步：先把世界推进到稳定态（量表恢复 / 冷却 / 状态与区域计时 / 界域计时），再授予机会——推进与授予严格分离；离场（detached）单位计时冻结。
- 机会下的可选行为 = 下方「行为可用性过滤」清单；资格校验（有无机会）与成本校验（资源是否够）相互独立。
- 单位采取行动的**同一机会内可连续行为**，直到无可用行为或主动结束（cost.opportunity 标记行为是否消耗机会）。

## 行为可用性过滤（固定顺序，结果确定）

可选行为底集 = 已装卡槽的技能 ∪ 基础行为（**普攻 / 移动 / 跳过**）；行为封锁（disallowActions）逐项禁用，禁光则该机会只剩跳过。

1. 卡槽冷却中 → 不可用
2. 装备牌：其装备实例仍在线 → 不可重打（防自我顶替刷新）
3. 强制行为白名单（force 类状态）→ 只放行名单内行为
4. 吟唱/引导中 → 不可用（可打断）
5. 能量不足以支付费用 → 不可用
6. 行动条不足以支付费用 → 不可用

## 伤害链（有序减伤管道，阶段固定）

一次伤害按固定阶段顺序结算，配置决定组成、顺序不可重排：

1. **护盾段**（LIFO）：护盾池吸收任意元素的非 DoT 伤害
2. **护甲段**：只抵消有形伤害——无形元素（精神/圣神/黑暗）与 DoT 绕过（INV-11）；支持比例破甲
3. **抗性段**：元素抗性乘性，钳制 [-50%, +75%]
4. **防御段**：防御线性减法
5. **乘区段**：状态持续乘区（增伤/减伤/易伤）、维度乘区（dimHooks）、界域 empower 乘区（DoT 不进本段）

旁路规则：DoT 只过抗性段与乘区段（跳过护盾/护甲/防御）；lethal（直连死亡）跳过全部减伤。

## 资源池（单位级）

| 池 | 说明 |
|---|---|
| hp | 生命；上限独立属性 |
| energy | 能量；行为费用货币，每 tick 回复 |
| shield | 护盾；伤害链第一段吸收；无装备依赖 |
| armor | 护甲；只源于当前护具（INV-11）；强化规则见编队上下文 |
| lost | 迷失值；只增不减，阈值档惩罚（档位载荷随英雄迁移登记） |
| lust | 恶欲值；可增可减（通道玩法） |

战场级量表（secrecy / order / fate_value / luminance / conflict）归战场上下文。

## 元素与抗性

- 元素是**纯标签**（无内建数值语义）；伤害类必填，其余填 none。
- 抗性槽按元素开设（火/冰/毒/雷/精神/物理/圣神/黑暗 + 全元素通配）；抗性只影响伤害链③段。

## 目标选择

- 选靶分两步：射程（reach，近战/远程…）+ 选靶请求（faction/anchor/sort/pickCount）。二者正交（INV-20）。
- 候选池过滤（单位类型/标签/状态持有/血量百分比等）是选靶请求的过滤面，不改变 anchor 语义。
- 必然命中（neverMiss）与隐匿/不可锁定（conceal 类别 + see_through 识破）是候选池与命中层的反制成对概念。

## 行为流水线（I→R→M→O）

> 决策期（选目标、算成本）与动作期（转向、结算）物理隔离：I 节点产出的 committedTargets 是干净快照，动作期只在其上做增量改写，绝不回写。主动行为、被动触发、状态触发统一走同一薄接口（ActionSource：ignition + targetSpec + effects）与同一流水线。

### I 目标解释（候选池 → 收缩）

1. **候选池**：按 mode 定池——`unit` = faction 圈定的单位实体集合；`area` = anchor + scope 圈定的坐标区块。池内过滤（filter 谓词 + 不可被选中排除）**先于锚点解析**生效，被排除者不占排首；排除强度分档（single 只挡指定型、all 连 AoE 一并挡）。每个坐标附 occupant 快照——空坐标是合法目标（召唤落位依赖此）；离场（detached）单位不进任何候选池；候选为空返回空集，上层跳过而非抛异常。
2. **收缩**：auto 按 sort 取前 pickCount（area 取区内全部在位单位）；manual 候选数 ≤ pickCount 全取、不打断玩家，> pickCount 等待玩家输入，无玩家在场走 fallbackSort。**fallbackSort 必填**——状态/被动触发没有玩家在场，缺兜底将依赖未定义行为，直接违反零随机（INV-4）。
3. 产出 committedTargets（不可变）+ stateVersion；提交时校验战场是否变动，不一致重算候选池。

### R 动作期干预（转向 + 结算计划）

- 逐 committedTarget 收集转向规则（自身 + 存活友军 guardTarget 指向它者），取 priority 最高者改写最终目标；**转向单跳，visited 集防环**（INV-23）；同优先级按既定默认序。
- 伤害随转向走（按最终目标的防御计算）；状态类效果留原目标。
- 绕行开关：任一 EffectRef 声明 ignore_redirect，或 Action 被嘲讽强制（I 节点打标记）→ 本 Action 整体跳过转向收集。
- 产出 finalTargets + 逐目标结算计划 + redirectLog；本节点不执行结算。

### M 消费分流

| 模式 | 行为 |
|---|---|
| instant | 每个 occupant 非空的 finalTarget 进 O |
| zone | 逐坐标注册 Zone（落点不依赖 UnitId；含位移/生成载荷的恒落己方半场） |
| summon | 取 occupant 为空的坐标落位新单位 |
| domain | 注册 DomainInstance（不经 Placement，规则作用于全场） |
| translocate | 目标经 Placement.remove 离场置 detached，到期经 Placement.insert 回归己方队尾 |

### O 结果应用

逐效果、逐目标：condition 逐目标判定（可「群攻只烧残血」），命中则执行、入 outcomes、发事件。**群攻 = N 条独立结算链**，不是一次算总再分摊（INV-24）。

**Action 状态机**：ignite（Commit = 消耗机会+扣资源 / EventTrigger = 不消耗）→ castTime == 0 直接结算，> 0 先入 Channeling 引导（见编队上下文）→ 走完 I→R→M→O 后 Resolved。

**目标改写（target_override）生效点**：在 I 节点覆盖选靶请求；层级 = target_override（含嘲讽强制）> 行为显式 targetSpec > 缺省目标基准；聚合规则覆盖（后者胜）、单跳不递归；反制开关 = target_override_immune。

**连击计数（cast_chain）**：施法者级 {tag, count}——技能进入结算时若与上一张已结算技能存在 tag 交集则对应 tag 计数 +1，无交集或跨回合全部归零；谓词 tag_chain 读取。纯计数器、不改写行为本身，配合费用修正生效。

## 近战同步对撞（基础机制，2026-10-31 由姿态专属改为基础规则）

任何 reach=melee 的攻击行为（普攻与近战技能）按同步对撞结算——不再要求防守方持有姿态（决斗姿态已移除）：

- **触发**：攻击 reach=melee ∧ 防守方（主目标）存活 ∧ 未被剥夺还击能力（眩晕/冻结/睡眠类硬控、不可行动）。**近战即贴身肉搏——对撞在攻击触发瞬间必然发生，无射程豁免**（2026-11-01 口径：不是反击，不适用「够得着攻击者」条件；战祸跨路普攻亦照常对撞）。
- **同步语义**：主攻击与对撞两条伤害结果各自纯函数计算后**同时应用**——对撞致死不中断主攻击（同一刻）。
- **对撞伤害**：防守方攻击力正常档（**不削减、不进武器加值、不耗武器耐久、无元素**），属行为伤害，进通用乘区（区别于状态来源伤害）。
- **防环**：对撞动作不再触发 on_take_damage（反向动作走一次，防二次链）。
- 近战技能可改写为「普攻 + 附加伤害」模式：基础攻击段照常吃对撞，技能价值在附加段（层三卡面口径，随第二英雄迁移逐步采用）。
- 反击姿态（远程顺序回击）与守卫姿态（拦截投掷）不受影响，仍按姿态持有生效。
