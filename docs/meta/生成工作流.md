# 生成工作流（分层产卡流水线）

> 用途：第二英雄及后续新内容的统一生成/回归约束；借鉴 CardGame 参考源的 GENERATION_BRIEF / DESIGN_CHECKLIST / rounds 蓝图章，
> 只吸收机制层纪律（自含精简版，上游全量文件不迁入）。SCORING 2.16 的指纹/蓝图双轨对账/角色六值是旧库防同质化设施，v2 不搬。
> 机读约束正源：`docs/json/schema/skills.schema.json`（原语 oneOf、触发点、卡型、五池）；机制纪律引 `ddd/params/编目参数.md`，本文不复制枚举。

## 总则

- 五层单向推进，每层过人审 Gate 才进下一层；禁止从层一直接写卡。
- 新枚举/新原语先走「环节⑥ 机制准入纪律」（WORKFLOW.md）：schema → 全链同步 → 数据才可用。
- 机筛：层三/层四统一跑 `docs/tools/review_scan.py`（warn 级）+ 四门禁（硬）。

## 层〇 命题与蓝图

- **输入**：`meta/家族身份卡.md`（主签名 + 红线）、`meta/骨架重议.md` §二·五（选材池）、目标派系蓝本池与 global 状态。
- **AI 产出（三表）**：
  - 命题表：一句话命题 + 可操作变量 + 变量的代价/输面（三格缺一不可）。
  - 轴玩法表：每轴一行：锚点（kind:id）+ 产层 → 读层 → 清除 + 决策点 + 计划卡数（轴合计 ≈22 英雄卡 + 家族公共卡位）。
  - 跨轴钩子表：卡位 / 读哪条轴 / 钩子语义（facet）。
- **Gate**：≥1 个变量可主动写、≥1 个读、有代价；签名维度不与既有家族撞车（家族身份卡 §三仲裁）；主人拍板。
- **落点**：本文「迭代记录」节追加一节（英雄代号 + 日期 + 三表快照），不进 ddd。

## 层一 机制骨架稿

- **输入**：层〇拍板三表。
- **产出**：每轴产层→读层链清单（哪个卡位产、哪个卡位读、谁清）；def 需求清单（状态/单位/界域/区域，含归属判定）。
- **归属判定（五判据精简）**：身份状态必私有（机制词汇即该途径专属）；通用减益/控制按机制词汇归 global；同名换皮合并；跨派系复用才上 global；蓝本池内先查缺才新建。
- **Gate**：每条链 ≥2 写 ≥1 读（防悬空读层——待办 §四有 13 条先例）；def 需求先对蓝本池/global 查重。

## 层二 数值定档

自含精简锚点表（粗检线，全量平衡另立平衡期）：

| 锚 | 档 |
|---|---|
| 一卡预算 | 3 能量 ≈ 6 伤害 ≈ 10% 最大生命 |
| 伤害换算 | 直伤 = 1.2 × 能量（标准技 3 能 → 5 伤带附加） |
| 属性档 | 攻防 ±1~±2；护甲 5 一档；行动条速率 ±5~±8 |
| 乘区 | 只作兜底（同类取最优）；常驻乘区须审批档 |
| 吟唱 | N tick ≈ 0.5×N 能量折扣，须写进 cost |
| 越档粗检 | review_scan R10 只报越档不评平衡 |

- **Gate**：每卡定价写出换算式；乘区逐条对照乘区纪律。
- **落点**：卡面 cost/describe；层二不做全量平衡。

## 层三 卡面落地

卡 8 步（机读精简，逐步一句；全量判据见 DESIGN_CHECKLIST 参考源）：

1. 定位：轴 + 产/读角色（产层卡还是读层卡）。
2. 骨架：kind/hook/rarity（rarity 由 sequence 定死，manifest.rarityMap 机器换算）。
3. AST：先定 target.mode；偏离缺省（敌方同路最前排）才写 request。
4. 硬约束：R1–R6（随机治理）、位移纪律、数值带——引用 ddd，不抄。
5. describe：逐卡手写，不写模板句；元素声称必须与效果一致（validator 机抓）。
6. 附属 def 成对：domain 原语 ↔ domainDef、zone ↔ zoneDef、unitId ↔ unitDef 不缺漏。
7. 元数据：tentative 按需；tags 用开放词汇。
8. 门禁：四脚本全绿 + review_scan 该英雄组 0 warn（豁免登记）。

状态 7 步精简：身份（四要素：乘区/duration/触发点/作用对象）→ 时长模型（duration/stacks/charges 三选一语义）→ 读档能力（threshold/statPerStack/ramp/phases 至少其一，叠层必有读档）→ 行为载荷（triggers/modifiers 走封闭集）→ 归属五判据 → 蓝本池登记 → 数值定档。

## 层四 回归验收

- review_scan 该英雄组 0 warn（豁免须注明理由，入回归报告）。
- 四门禁全绿；`meta/迁移映射表.md`（或迭代记录）同步登记。
- 回归报告归档 `meta/回归/`，一节一英雄。

## 质量红线（违反即打回）

1. 效果必落封闭原语；描述性词语不进效果字段。
2. 数值先换算再写卡。
3. 新状态四要素齐（乘区/duration/触发点/作用对象）。
4. on_spawn 不当开局触发用；on_kill ≠ on_death，语义不得混。
5. 概率走 `condition.chance`：R3 登记、R4 单次抽样、R5 非伤害维度；目标选择零随机。
6. 家族红线违反即打回（引家族身份卡 §二）。
7. 叠层状态必有读档出口；悬空读层（只读不产）禁入。
8. 互斥概率分支写嵌套 if 链，禁并列独立 chance if。
