# faction_07 血巢

> 派系底座：血肉生命的孕育与蜕变。一切都是孕育——急不得，也抢不走；以时间换强度。

## 基准机制

- 普攻伤害：1（基础位无攻击行为）。
- **普攻栏位替换为「消耗自身 1 血，为友方恢复等同自身攻击值的血量」，10tick CD**。
- 奶量取实时攻击总值，但只认**直接攻击修正**（增伤乘区/伤害类状态不生效；「增加恢复量」类效果可提升）；**持武器时被武器逻辑覆盖、不能加血**；目标**含自身**（1 血换 2 血净回 1）；消耗钳 1 不致死。
