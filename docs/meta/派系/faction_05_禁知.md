# faction_05 禁知

> 派系底座：荒芜、禁忌、会致疯的隐秘知识。知道得越多越接近门槛；星空是共享的，先到者立法。

## 基准机制

- 普攻伤害：1；**术法（reach=spell）**、站位无关。
- 选靶 = **敌方任意位置单个单位**（非全体伤害）。
- **双向不致死**：目标与自身都最低钳 1 血（知识只能伤人不能夺命）。
- 反噬 = 与攻击同额掉血、**不可防**（无元素、不吃护甲/护盾/减伤、不可转移）。

## 派系定位（2026-11-04）

**「知识」派系——禁忌的两种用法：解读与编写。** 两族一考古一工科：

| 家族 | 用法 | 一句话 |
|---|---|---|
| pryer | 读世界 | 发掘被埋的：数值抄你的、法则租来的、知识卷轴预存 |
| savant | 写世界 | 规律是图纸、造物是产品线、缺陷是质检清单 |

「知道得越多越接近门槛」两面落地：pryer 知识淤积（灌输错乱的反噬）、savant 补全自身（趋近完美即跨门槛）。基准双向不致死正是这种「伤而不杀」的冷感。

## 派系共享机制（2026-11-04 提取）

- **知识税口径**（设计约束，非机制）：禁知的卡一律「有代价的知识」——每卡带参照（valueFrom）/预存（卷轴/阶梯）/改写（规律）维度之一，收益越大代价越重；禁入无代价白嫖卡。层三约束、层四校验。
- **科学侧规则槽登记**：规则槽写家里律庭占社会侧（06 禁与价 / 07 扭曲），禁知占科学侧——pryer 星象法则（预设表条款）+ savant 物理规律（重力/材质/距离）。口径：科学侧条款须挂参照物或材质参数（valueFrom/材质），不挂社会性惩罚语义。
- 派系蓝本池（faction_05，当前为空）预留：第二英雄落地时入此层。

## 家族 ↔ 派系联系

- **pryer**（英雄·伍在册）：知识掮客——术法全图点杀 = 窥秘之眼的火力版；反噬 = 知识淤积的自伤面。
- **savant**（候选）：完美工厂——全图点杀 = 规律武器化；伤而不杀 = savant 的暴力是工程不是屠戮（修复划界 #5 的气质延伸）。
- **两族互补**：pryer 从世界里挖规则漏洞、savant 给世界写新物理——禁知一家的读写。
