# faction_01 暮河

> 派系底座：万物走向终点、落幕归永暗。收束、沉降、终局之美——光是借来的，迟早要还。

## 基准机制

- 普攻伤害：**空手 2 / 持武器 = 武器伤害**（不跨路）。
- 空手 +1 且自耗 1 血（最低钳 1 不致死）；持武器时普攻被武器接管，不 +1 不耗血。

## 派系定位（2026-11-02）

终末派系——三家族是终点的三个切面：

| 家族 | 终点的切面 | 一句话 |
|---|---|---|
| warrior | 战斗的终点 | 交手即落幕——敌人与我动手就开始衰败 |
| corpse_collector | 生命的终点 | 死亡不是事件，是账目——凡死者皆入簿 |
| sleepless | 一日的终点 | 白昼谢幕、万籁安眠——夜里我值守 |

靠「一切有代价、有终点」赢，不靠增益。派系基准「空手 +1 耗血」即 warrior「装备即本体、肉身即武器」的下沉——warrior 是暮河的原型家族。

## 派系共享机制（2026-11-02 提取）

- **暮色相位**：sleepless 的夜幕相位引擎上升为派系底盘——相位处于夜/暮档时三家族各挂读层：warrior 衰败铺层加速（aging 产层节奏）、corpse_collector 亡灵军团维持费打折、sleepless 引擎本体（收益随相位起落，不动）。拨时权归 sleepless（身份卡 §三索引 03=赶夜入夜，与 13 命运回拨/17 仪式昼夜已分叉）。第二英雄落地时逐族细化读层。
- **终末记账口径**（设计约束，非新机制）：暮河的状态一律「有账必有清算窗口」——铺层必带兑现/崩解出口，存款必带花费场景，账簿必带可拆性；层三产卡时约束三家族，层四回归校验。
- 派系蓝本池（faction_01，当前为空）预留：第二英雄选材时若三家族共用蓝本（如暮色界域 domain）即入此层。

## 家族 ↔ 派系联系

- **warrior**：衰败引擎直接演绎「万物走向终点」；守护替承 = 把队友的终点往后推。
- **corpse_collector**：死亡账房 = 「迟早要还」的账目形态；冥界 = 落幕归永暗的字面落地；灵视 = 永暗中的眼睛。
- **sleepless**：长夜值守 = 落幕之后的时段管理；白昼蛰伏弱项 = 「光只是借来的」的代价面。
