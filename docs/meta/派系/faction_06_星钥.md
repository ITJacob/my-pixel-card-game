# faction_06 星钥

> 派系底座：星辰命运，开启与通道。命运是一扇摆动的门：押对方向门开，押错方向门关。

## 基准机制

- 普攻伤害：1（名义值，无普攻行为）。
- **普攻栏位替换为「获得幸运币」，20tick CD，消耗行动机会**。
- 幸运币 = 独立临时实体（≠ 幸运层）：10tick 窗口内受伤即被夺（**归攻击者**）、无恙满 10tick 转化为幸运层 +1。

## 派系定位（2026-11-04）

**「命运」派系——单族派系：monster 一系即全派系。** 全家围绕「命运账户 + 门的开关」：

| 底座要素 | 落地 | 状态 |
|---|---|---|
| 星辰命运 | fate_value 账户 + 命运潮汐 + 灵感预言 | ✅ 在册（星轨庄家） |
| 开启与通道 | 星空通道/秘门——无实体 | ❌ 缺口（裁定 #7 保留） |
| 门（押对开押错关） | fate_value ≥+5 赐福 / ≤−5 反噬 | ✅ 在册 |

缺口处理：monster 第二英雄轴 = 星空通道/秘门（同族新轴，选材时补实体）——开「命运的门」不开「时空的门」（与学徒 #7 划界）。

## 派系共享机制（2026-11-04 提取）

- **幸运币 = 派系通货**（基准层上升）：星钥派系统一攒运入口——未来第二英雄/家族的产运动作一律经幸运币（10tick 窗口、被夺归攻击者、转化幸运层 +1 的公理不变），除非家族机制明确另有产层。fate_value 写入权仍 monster 独占，不动。
- **门语义口径**（设计约束，非机制）：星钥的卡一律「命运有价」——收益必挂 fate_value/幸运层出处（押哪一极、窗口多长），禁入无出处白捡的好运；「门」类效果必写开关条件。层三约束、层四校验。
- 派系蓝本池（faction_06，当前为空）预留：星空通道类 zone/定义落地时入此层。

## 家族 ↔ 派系联系

- **monster**（英雄·陆在册）：星轨庄家——幸运币是 fate_value 体系的入户单元（攒运最小动作放普攻位，放弃普攻换攒运）；币被夺 = 命运可被抢、无恙转层 = 攒运有窗口；幸运层兑换（赐福/赢家免死）接币的转化端。

（注：fate_value 写入、命运潮汐、重启循环 = monster 独占，均不提取。）
