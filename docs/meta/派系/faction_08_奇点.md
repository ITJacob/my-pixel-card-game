# faction_08 奇点

> 派系底座：万物从这里诞生（创世·全知）。风雷雨按序降生；窗口之前，万物未成。

## 基准机制

- 普攻伤害：1；melee。
- 选靶候选集 = **同路队首 + 同路次位**（manual 玩家二选一；auto 按 sort 缺省取队首）——选靶流程见共享内核参数 §一。
- 伤害同额 1 不递减；候选按占位投影**实时读**（不锁定）；直取次位为近战 ⇒ 照常触发对撞。

## 派系定位（2026-11-04）

**「创世」派系——万物从奇点诞生，五族是创世五职。** 全库最大派系（sailor 在册 + 四候选）：

| 家族 | 创世之职 | 一句话 |
|---|---|---|
| sailor | 降生 | 风雷雨按序降生：元素装配线 |
| chanter | 立光与约 | 正午圣光 + 公证契约：让世界有法 |
| reader | 全知 | 解析万物原理：窗口之前我已知道 |
| spectator | 定义 | 位格洞察 + 空想成真：我说什么是真的 |
| supplicant | 牧灵 | 放牧灵魂、契约交换：灵魂由此出入 |

两组分界：**造**（sailor 降生 / chanter 立约）与**知**（reader 解析 / spectator 定义），supplicant 横跨（灵魂牧场 = 生灵的来处）。基准「选靶 = 队首或次位」也是创世序——攻击落在最先生成的两个位置。

## 派系共享机制（2026-11-04 提取）

- **按序口径**（设计约束，非机制）：奇点的卡一律「有先有后」——多段/多目标效果必带顺序语义（按序结算、先生成先触发、断档有后果）；呼应「按序降生、窗口之前」。sailor 连锁引擎即范例。层三约束、层四校验。
- **派系通用卡 = 常规效果，风味在家族层（2026-11-08 主人裁定）**：f08 通用卡只做常规身材/输出（初生、原初洪流、创世序、奇点爆发），「时间序/按序降生」的风格特点由家族卡与英雄卡承载（gauge_rank 读下一动者、自身位次竞速——j08 后续批与第二英雄落地）。
- **洞察面登记**：reader 解析既有世界（读）/ spectator 定义新世界（写）为派系内互补；先知语义已裁定 #2（monster 灵感 vs reader 逻辑），spectator 走定义面不入先知系。
- 派系蓝本池（faction_08，当前为空）预留：五族共用蓝本第二英雄落地时入此层。

## 家族 ↔ 派系联系

- **sailor**（英雄·捌在册）：天灾流水线——双位选靶 = 装配线前两工位；元素连锁「按序、断链作废」是「按序降生」的机制态。
- **chanter**（候选）：正午公证处——圣光与契约是创世的「立法光」。
- **reader**（候选）：情报交易所——全知 = 底座字面落地。
- **spectator**（候选）：观众席——定义面创世，与 reader 读/写互补。
- **supplicant**（候选）：灵魂牧场——灵魂由此出入（混沌海一系归属已注记；转嫁灾祸划界仍挂层〇）。

（注：元素连锁/契约窗口/读维记忆域/位格空想/放牧血肉 = 各家族独占，均不提取。）
