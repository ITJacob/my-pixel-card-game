# faction_03 律庭

> 派系底座：秩序、王权，秩序与崩坏。立规矩的人也跪在规矩里；王权与崩塌是一体两面。

## 基准机制

- 普攻伤害：1；**术法（reach=spell）**——无对撞、站位无关。
- 选靶 = 任意单位（**含己方**）；**10tick 冷却**（冷却只锁普攻键，不锁行动机会——全库 CD 通则）。

## 派系定位（2026-11-04）

**「规则」派系——世界法理的两面：立法者与弑法者。** 两族是秩序的正负两极：

| 家族 | 极 | 一句话 |
|---|---|---|
| arbiter | 秩序之正 | 我立法：禁与价写进规则槽，违例自动开庭 |
| lawyer | 秩序之反 | 我不立法，拆你的法：扭曲、判例、王权疆域 |

底座「立规矩的人也跪在规矩里」字面落地：arbiter 立规矩（自己也受约束——豁免须付代价），lawyer 跪在规矩里钻空子直至篡位。规则槽四分里律庭一家占两个（06 立法 / 07 扭曲，身份卡 §三索引）。

## 派系共享机制（2026-11-08 体系 v3 定稿：基础法条 + 补丁/贿赂 + 吟唱打断）

- **基础法条库（派系公共底盘）**：游戏机制的法律化表述，永远生效、可被规则槽锚定——art_energy 使用技能必须消耗能量 / art_phase 白天之后必须是黑夜 / art_weapon 使用武器必须消耗耐久 / art_death 血没了必须死亡 / art_move 移动必须遵守插入语义（登记见 SCHEMA.md §5·五）。
- **arbiter = 打补丁（加固）**：吟唱 3tick 立法——给基础法条叠违例惩罚窗口（如「30t 内使用武器者受罚」），不改机制本体。法条库大而全：普适条文 + 裁量法条。
- **lawyer = 贿赂（搞混 + 豁免己方）**：吟唱 2tick——为指定单位买法条豁免（如「自己用技能少付 1 能量」）；可剔除敌方豁免、微调既有条文（适用定制，不立新法）。
- **order 双职能**：惩罚力度 ∝ order、贿赂代价 ∝ order——arbiter 推高 = 法律严明（罚狠、行贿贵）；lawyer 压低 = 法纪废弛（罚轻、行贿便宜，律师正反馈闭环）。order 初始 5，写入权两族分立。
- **吟唱 = 全场交互口**：立法/贿赂走 Channel（提交即承诺、打断作废、资源不退）——任何人可打断律庭的立法与贿赂，派系外参与系统级成立。
- **规则系口径**（设计约束）：律庭的卡一律「成文」——效果来源可审计（哪条条文/哪笔贿赂）；不产无出处的效果。
- 派系蓝本池（faction_03，当前为空）预留：两族共用蓝本第二英雄落地时入此层。

## 家族 ↔ 派系联系

- **arbiter**（英雄·叁在册）：秩序法庭——术法任意单位含己方 = 执法无禁区，己方违例同样制裁；10tick CD = 开庭有节奏。
- **lawyer**（候选）：秩序黑客——术法打己方 = 「先立后破」的靶子制造：把己方变成可援引/可扭曲的先例，普攻也是规则操作。
- **两族同桌**：arbiter 写条文、lawyer 改条文——同一套规则槽，一个建设一个解构；对面站着时就是立法权争夺战。
