# faction_03 律庭

> 派系底座：秩序、王权，秩序与崩坏。立规矩的人也跪在规矩里；王权与崩塌是一体两面。

## 基准机制

- 普攻伤害：1；**术法（reach=spell）**——无对撞、站位无关。
- 选靶 = 任意单位（**含己方**）；**10tick 冷却**（冷却只锁普攻键，不锁行动机会——全库 CD 通则）。

## 派系定位（2026-11-04）

**「规则」派系——世界法理的两面：立法者与弑法者。** 两族是秩序的正负两极：

| 家族 | 极 | 一句话 |
|---|---|---|
| arbiter | 秩序之正 | 我立法：禁与价写进规则槽，违例自动开庭 |
| lawyer | 秩序之反 | 我不立法，拆你的法：扭曲、判例、王权疆域 |

底座「立规矩的人也跪在规矩里」字面落地：arbiter 立规矩（自己也受约束——豁免须付代价），lawyer 跪在规矩里钻空子直至篡位。规则槽四分里律庭一家占两个（06 立法 / 07 扭曲，身份卡 §三索引）。

## 派系共享机制（2026-11-04 提取）

- **秩序-熵双极量表**：一张战场量表两极——秩序极（arbiter 推高：罚则乘区放大）与熵极（lawyer 推高：扭曲强度/豁免权柄放大）。同派系两族同场互相拉扯一张表；单族出场只推自己那一极。与星钥 fate_value 形态相似语义分叉（星钥押个人命运，律庭扯世界法理——登记裁定 #9）；与战祸冲突计数不同源（计规则事件而非伤害事件）。
- **规则系口径**（设计约束，非机制）：律庭的卡一律「成文」——每卡须与规则槽/立法/扭曲/判例/豁免相关联，效果来源可审计（哪条条文导致）；不产无出处的效果。层三约束、层四校验。
- 派系蓝本池（faction_03，当前为空）预留：双极量表定义即入此层。

## 家族 ↔ 派系联系

- **arbiter**（英雄·叁在册）：秩序法庭——术法任意单位含己方 = 执法无禁区，己方违例同样制裁；10tick CD = 开庭有节奏。
- **lawyer**（候选）：秩序黑客——术法打己方 = 「先立后破」的靶子制造：把己方变成可援引/可扭曲的先例，普攻也是规则操作。
- **两族同桌**：arbiter 写条文、lawyer 改条文——同一套规则槽，一个建设一个解构；对面站着时就是立法权争夺战。
