# faction_09 欲狱

> 派系底座：欲望、堕落、诅咒、禁锢。力量都是债——要血肉、要放纵、要反照。

## 基准机制

- 普攻伤害：1；melee。
- 命中给**自身与目标同附 5tick 束缚**（束缚期间不可移动）；双方束缚各自计时、各自可被驱散。
- 束缚即 immobilize（纯禁位移）状态——本行为是其首个登记用户，状态建 definitions 时从欲狱普攻反向落地。

## 派系定位（2026-11-04）

**「沉沦」派系——债的两种方向：欠下的与承受的。** 两族：

| 家族 | 债的方向 | 一句话 |
|---|---|---|
| criminal | 放纵之债（欠下的） | 越用力量越堕落：恶欲灌池、刻印累积、养敌之欲反噬其身 |
| prisoner | 苦难之债（承受的） | 越扛苦难越异类：诅咒反照、苦难换坚韧、谱系推栈不回头 |

底座「血肉、放纵、反照」：criminal 三样全占，prisoner 是反照专业户。堕落与禁锢一体两面：基准「双向束缚」就是沉沦绑定——锁人先锁己。

## 派系共享机制（2026-11-04 提取）

- **反照口径**（设计约束，非机制）：欲狱的卡一律「有债必反照」——增益必带代价面（血肉/刻印/异类化），减益必带反噬风险；禁入「干净」的效果。层三约束、层四校验。
- **爆档线登记**：欲狱的账户/层数一律带爆档线，爆档即失控（效果反噬持有者）——criminal 恶欲 ≥6 提前引爆 / prisoner 迷失值爆档异类化为两族实例；两表独立不合并（恶欲池与战祸冲突计数已裁定 #8 分叉）。
- 派系蓝本池（faction_09，当前为空）预留：第二英雄落地时入此层。

## 家族 ↔ 派系联系

- **criminal**（英雄·玖在册）：欲望污水厂——双向束缚 = 放纵的连锁：打你就是拖你一起沉。
- **prisoner**（候选）：苦难银行——束缚是本职（禁锢专业化已登记），基准的 5tick 束缚是免费开场白。
- **两族对表**：criminal 恶欲池对着血巢丰饶（荒芜侵蚀读层）；prisoner 苦难账户对着 chanter 圣光天克——欲狱的债表都有天敌。

（注：恶欲池产读结构 = criminal 独占；诅咒链/谱系栈 = prisoner 独占；双向束缚本身 = 基准层，均不上提。）
