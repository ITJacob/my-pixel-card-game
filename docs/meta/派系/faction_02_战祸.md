# faction_02 战祸

> 派系底座：冲突、战争、灾厄毁灭。火上浇油，越打越旺；灾不是意外，是常态。

## 基准机制

- 普攻伤害：1；melee。
- 选靶 = **锚定回退链**：首选本路敌方队首；本路无敌方单位时才可指跨路队首（多路均有队首时 manual 手选 / auto 按路序取第一条非空路）。**非全场任选**。
- 对撞照常（近战必然对撞，INV-29）。
