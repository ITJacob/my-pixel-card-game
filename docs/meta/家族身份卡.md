## 一·五、本质与在册机制映射

> 主人给定「核心本质 + 能力调性」，映射到在册机制（2026-10-31 起逐家族过稿；命题定稿在映射完成后另立一轮）。

### family_01 warrior

- **核心**：黄昏、衰败、终末、巨力、落幕——不是光明系，是光明的终点；黎明之光只是黄昏前夕的回光。
- **调性**：极致肉身与防御（肉身最强一档）；破晓净化；高段自带衰败领域、崩坏万物。
- **在册机制映射**：martial = 极致肉身/武器耐久线（格斗连击、武器大师、破甲重击、黄昏巨剑）；guard = 正面承伤与守护（死斗、守护状态、银色全身甲、黎明铠甲）；twilight = 老化 → 崩解 → 将死宣判（迟暮产层；万物崩解、神罚、黄昏重生、处决登记读层兑现）；holy 仅现于破晓净化语境（神圣·荣耀、黎明铠甲），不展开为光明系。

### family_02 corpse_collector

- **核心**：死亡、亡灵、摆渡、永眠、生命终点——纯粹生死权柄，一切生命的最终归宿；暮河三系里最直白的「终末」。
- **调性**：招魂、亡灵军团、灵魂掌控、生死切割；主打亡灵大军与灵魂审判。
- **在册机制映射**：家族签名 = filter.unitType 灵视克制 + on_kill 死亡结算（身份卡 §一）。选材池机制面（源 43 卡已勘探）：undead = 亡灵军团（骷髅/活尸/亡魂三蓝本 + 召唤 cap + 维持费）；end = 死亡账本（铺账 → 催账/收账 → 权柄合并结算，可净化拆账），摆渡与生死切割语义由阈值处决承载（摆渡·对视、死亡宣告）；spirit_sight = 灵视克制（对隐匿 ×1.5 + 识破驱散）；corpse = 尸体特质（自持坦度，多卡以「自带尸体特质」为门槛联动）。红线不冲突：死亡是过程不做即死；军团受 cap；账本必须可拆。

### family_03 sleepless

- **核心**：黑夜、安眠、隐秘、守护、长夜终末——掌控夜晚、梦境与沉寂，让一切归于安眠；寂静与守护的终末体系，克制疯狂与躁动。
- **调性**：夜视、潜行、梦魇、安抚与沉寂。
- **在册机制映射**：家族签名 = on_phase_change 相位触发 + advance_clock 拨时入夜 + secrecy 隐秘资源深化（身份卡 §一）。已回填蓝本（悬空读层迁入派系池）：covert_veil 潜匿（出手自破）、occult_seal 隐秘封印（双向绝对封印）、conceal_authority 隐秘权柄（授予潜匿 + conceal 类不可驱散）——三张已被 h02/h03/h05 跨系读层，是现成的枢纽资产。选材池机制面（源 34 卡待层一逐张勘探）：夜幕相位引擎（advance_clock 推夜，收益随相位起落、正午弱项对称），夜色层数存取（secrecy 夜里存白天花），梦魇压制（fear/dread 语义——与 monster「厄运惊惧」共享 fear 系但语义分叉，撞车裁判需注记），安抚沉寂（silence 系，反躁动——克制 monster 疯狂/命运反噬面）。红线不冲突：不走 holy/火；暗夜收益必随相位起落。

### family_04 assassin

- **核心**：畸变、魅惑、命运扭曲、极致灾祸欲望——高速高诡、极致灵动；自带灾祸属性，越挣扎越容易坠入畸变；混乱、欲望、灾厄体系。
- **调性**：幻术、魅惑、敏捷、命运扰动、异变。
- **在册机制映射**（英雄·贰在册）：form = 异变与形态（影/雾/血三形态轮转、隐形与阴影躲藏、女巫之形——自身魅惑与误导不可驱散）；mirror = 幻术与命运扰动（镜映借序：镜子替身、魔镜占卜、镜中迷宫、镜中世界；charm_axis 魅惑满层转不可驱散、bewitch 误导——把刀递向自己人即微观命运扭曲）；plague = 灾祸属性（黑焰、冰霜、疾病——灾祸欲望的具现，疫由焰生）；敏捷面 = 羽毛轻盈（受击后撤消耗）与鹰的视力。红线不冲突：镜子语义绑定、输出必带闪避/替身/换位——正是「高速高诡、不正面站撸」的机制表达。派系底座呼应：战祸「借力」——借对手之招，灾祸自携。

### family_06 arbiter

- **核心**：律法、惩戒、秩序、裁决、规则审判——依靠世界法理审判敌人：锁定罪行、制裁违规、封印失控；硬性秩序，专治混乱、失控、邪祟。
- **调性**：封印、惩戒、执法、压制罪恶。
- **在册机制映射**（英雄·叁在册）：decree 轴 = 审判核心——write_rule_slot 立「禁与价」（no_skill/no_attack 写入 Rules[3] 槽）+ 违例 punish 载荷（decree 状态承载惩罚：精神伤害 + 枷锁），立规/囚禁/惩戒/禁制追击同族；jurisdiction 轴 = 执法空间——辖区（zone_jurisdiction 数值辖区：己方增益/敌方迟滞）、位格管辖与位格律令（位格低于我者：我减伤、我增伤——执法有门槛）；inquest/support = 锁定罪行——屈服、精神刺穿、过目不忘（marked 破绽标记，读层追加伤害）；order 秩序度 = 世界法理账户——四张写入卡供源，秩序推高则律令乘区放大（法系越稳罚越重）；封印失控 = 废除/基石规则/立规封技，满月显形破隐匿对治邪祟。红线自洽：只立禁与价、违例必罚、豁免必付代价（豁免账/权威转移）。

### family_08 seer

- **核心**：历史、时空、命运、愚弄与奇迹——借力历史、制造「巧合与意外」，不正面硬刚，靠规则漏洞取胜；最全能、最诡谲的一系。
- **调性**：诡诈、隐匿、回溯、篡改概率。
- **在册机制映射**（英雄·肆在册）：marionette 轴 = 提线控场——灵体之线是唯一通货（puppet_string 层数引擎：牵线 → 秘偶换位/挡刀/秽物转移，借力已牵线的傀儡而非自身硬刚）；trick 轴 = 诡诈与奇迹——纸人替身（致死保护）、愚弄（打空 + 反噬 = 把意外还给对手）、幻觉、飞牌/火跃等小戏法、能力精进（嫁接：把自己的好处接到既有条款之后 = 规则漏洞的微观形态）、灵界庇护（detached 规避一切指向）；foresight 轴 = 命运与回溯——占卜/占星/预感/灵视（预判），灵体之线感知，读命运缝隙（fate_gap 跨系）即篡改概率的落点；隐匿面 = 幻境/纸人/灵界三窟。派系底座呼应：时隙「时空、历史、命运的奇迹与漏洞」——本质注记与底座几乎逐词对应。红线自洽：嫁接只改指向不改文本（与律庭划界），借序只借对手动作（与战祸划界）。

### family_11 pryer

- **核心**：隐秘、古老、遗迹、被隐藏的真相——掌管被掩埋的知识与历史：发掘隐秘、布置隐秘领域、隐藏真相。
- **调性**：探索、解密、操控遗迹、隐匿信息。
- **在册机制映射**（英雄·伍在册）：scrying 轴 = 发掘隐秘——窥秘之眼（看穿隐藏：对携带任意状态的目标增伤 + 识破过滤）、隐秘知识层数引擎（spell_lore 计数 + 耗层兑现）；astral 轴 = 遗迹与隐秘领域——星象共谋（推高共享隐秘星空 secrecy，先越门槛者在规则槽刻**星象法则** = 布置隐秘领域）、星光囚笼/星桥/星之巨柱（遗迹巨构）、预言与末日（被隐藏的真相揭封）、信息化（隐匿信息——穿梭期间不可被单体选中）；scroll 轴 = 古老的卷轴（冰冻/麻痹卷轴、闪电术、照明——知识以卷轴形态预存，cast_time_set 省时）；combat 轴 = 解密后的兑现——因敌施技（按目标状态选招）、朗基努斯之枪（驱散增益 = 揭穿庇佑）、知识淤积（灌输错乱的反噬）。派系底座呼应：禁知「荒芜、禁忌、会致疯的隐秘知识」——星象法则只能选预设表条款，正是「禁忌知识的可承受剂量」。红线自洽：valueFrom 必写参照物；卷轴省时不免施法。

### family_13 monster

- **核心**：星辰、命运轨迹、星空通道、开启与指引——执掌星空与星轨命运：预言、开启星辰通道、借星力加持。
- **调性**：星象预言、星空加持、开启秘门、命运推演。
- **在册机制映射**（英雄·陆在册）：命运轨迹 = fate_value 命运值账户（全库唯一登记写入方：≥+5 赐福乘区 / ≤−5 反噬档——星轨的两极，押对收租押错赔光）；双极 = 命运潮汐（低潮挨打攒运 / 高潮获取 ×1.5，命运之轮翻盘）；预言 = 灵感层（未来画面、危险预感、反占卜——星辰示警）；开启 = 循环重启（advance_clock 拨时 = 开门，restore_snapshot 回溯 = 倒转星轨，重启循环续接）；星空加持 = 幸运层兑换（赐福、赢家免死——星力入账与兑现）；星象 flavor 已有落点（相位触发的「星象翻页」）。**缺口标注**：星空通道/秘门类机制在册尚无实体——层〇选材可补（与学徒时空税划界：本族开的是「命运的门」，不开「时空的门」）。

### family_14 apothecary

- **核心**：幻梦、异变、血肉蜕变、阴晴圆缺——光影幻梦、血肉多变、真假难辨；伪装、蜕变、梦境侵蚀，血肉与幻梦一体。
- **调性**：幻术、变身、血肉畸变、梦境。
- **在册机制映射**（英雄·柒在册）：阴晴圆缺 = 月相五相轮转引擎（formGroup/cycleTicks：满月治愈强化 → 月亏 → 月残 → 月黑 → 血月，收益随轮转起落不锁相）；幻梦/真假难辨 = 药剂 conceal 面（隐身药剂当场半数/预服全效、无味免疫减益、月光化虚化）——伪装与蜕变的药剂形态；异变/血肉 = 兽群系（驯兽哨、兽群号令、wild_instinct 野性冲动、unit_beast / unit_elder_thing 蓝本）+ 血月（深红活力按层推月相）；变身 = 月光化（虚化 + 致死保护）与闪现；治愈本职 = 自疗、纯净之地、炼成（母巢系拿治疗本职，与秘祈人划界）。**缺口标注**：梦境侵蚀在册落点偏弱——与 sleepless 梦魇面撞车需划界（本族走「幻梦掩护」，不眠者走「梦魇压制」，层〇选材时定边界）。红线自洽：药剂必须预服/延迟兑现；月相收益随轮转起落。

### family_16 sailor

- **核心**：风暴、雷电、海域、极速与毁灭冲击——极致破坏力与机动性；雷霆风暴与海洋权柄，大范围清场，近远程皆凶猛，霸道爆裂。
- **调性**：狂暴、高速、大范围元素轰炸、控水控雷。
- **在册机制映射**（英雄·捌在册）：storm 轴 = 雷霆风暴主炮——元素连锁引擎（狂风写风键 → 风刃/雷击/连锁闪电/龙卷按序接续，三键齐全成天灾；严格按序、断链大额作废）+ 雷电之矢/雷罚/风暴地狱区域；ocean 轴 = 海域权柄——控水（深潜：不可选中、出手浮出；水之幕）、控雷（雷击系）、海兽召唤（unit_sea_beast）、风暴海界域（domain_sea_kingdom：己方增益/敌方迟滞）；rage 轴 = 狂暴（愤怒叠层 statPerStack，怒溢成冰——狂暴溢出转为冰霜附伤，元素轮转从卡面下沉状态面）；极速 = 加速与滑翔/飞行（行动条速率 +8、受击借风退尾、真飞行）；毁灭冲击 = 天灾降临（雷灾全体 + 击退，跨系读 misfortune 放大——霸道清场）与剑刃军团。红线自洽：天灾必带元素轮转（连锁键即轮转的结构化）；不走无元素物理伤害（狂风自带冰砾）。

### family_21 criminal

- **核心**：欲望、疯狂、沉沦、无尽堕落、深渊吞噬——无底沉沦：越使用力量越堕落，吞噬一切、腐蚀一切；纯粹欲望与沉沦黑暗。
- **调性**：狂暴、贪欲、腐蚀、同化。
- **在册机制映射**（英雄·玖在册）：lust 恶欲池 = 欲望账户（产：敌方行动浇灌 + 自卡推波；读：失控阈值 ≥6 炸弹提前引爆、欲望化身、恶欲共鸣满层——憋高层还是中层放的押注）；filth 污秽 = 腐蚀与同化（产：恶语成秽、秽土、侵蚀、硫磺剧毒；读：污秽之王放大、秽土深耕、荒芜侵蚀——腐蚀环境让对手体系失效）；demon 仪式 = 越用越堕落（恶魔仪式：自残 6 血换 8 能 + 仪式刻印，刻印是深渊召唤按 f(N) 映射的强化材料——力量有代价且代价累积）；elements 硫磺/岩浆 = 深渊火（狂暴面：岩浆之剑、硫磺火球）；沉沦闭环 = 深渊之咒与欲望炸弹（养敌之欲，反噬其身）。派系底座呼应：欲狱「力量必有代价——要血肉、要放纵、要反照」——lust 被敌方喂养=放纵，恶魔仪式自残=血肉，污秽腐蚀=反照。红线自洽：恶欲只涨于敌方放纵不来自自伤（仪式是能量包非 lust 产层）。

### family_05 hunter（候选）

- **核心**：战争、狩猎、杀伐、冲突、灾难爆发——战场之主：越乱越强、杀敌越强、统领军团；战争权柄、冲突激化、灾祸爆发。
