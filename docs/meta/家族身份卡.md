# 家族身份卡（22 张）

> v2 家族级设计权威（2026-10-29 由 CardGame 参考源《途径设计身份.md》压缩改写）。
> 用途两层：**撞车裁判**——跨家族共享维度须语义分叉，禁入红线违反即打回；**选材依据**——
> 第二英雄选材时核对家族身份与候选轴的契合度。英雄级身份随轴展开再细化（每家族约 4 轴）。
> 主签名维度全库唯一；次级共享维度必须语义分叉（同机制、不同诠释）。

## 二、家族红线速查

| 家族 | 红线 |
|---|---|
| family_01 warrior | 零吟唱（武技瞬发）；守护不走隐身/闪避，正面承伤。 |
| family_02 corpse_collector | 死亡是过程——走 on_kill 结算链，不做直接即死；亡者军团受召唤上限约束。 |
| family_03 sleepless | 暗夜收益必须随相位起落（有强项必有正午弱项）；不走 holy/火系。 |
| family_04 assassin | 镜子语义绑定（替身/拉入/穿梭三选一）；输出必带闪避/替身/换位其一，不正面站撸。 |
| family_05 hunter | 集众收益按在场人数缩放；target_override 只做指挥调防，不做顶替混淆。 |
| family_06 arbiter | 只立「禁」与「价」，不改写规则文本；立规必须有违例惩罚与豁免条款。 |
| family_07 lawyer | 扭曲必须「先立后破」——只改写已有规则槽/状态，不从零创造秩序。 |
| family_08 seer | 嫁接只能「移花接木」（改指向/换宿主），不改规则文本、不立新规；秘偶走层数引擎。 |
| family_09 apprentice | 一切收益必带「位移/换场/回放」的时空税——不拿永久增益与站桩 buff。 |
| family_10 thief | 夺取来的必须注明归还/时限——只有「持有中」，没有「拥有」。 |
| family_11 pryer | 数值必须按参照源缩放（valueFrom 动态取值），禁拍脑袋定值；卷轴省施法时间但不归零。 |
| family_12 savant | 规律改写限「物理规律」语义（重力/材质/距离），不碰社会规则与定义嫁接；造物必有材质/阶梯参数。 |
| family_13 monster | 概率只走 condition:chance 登记抽样且只用于非伤害维度；重启必须可回溯（快照语义），不做无条件重置。 |
| family_14 apothecary | 药剂必须预服/延迟（当场喝半数以下）；月相收益随轮转周期起落，不锁相。 |
| family_15 planter | 成长必须「时间换强度」，拒绝瞬发全额；荒芜与丰饶同卡必为双刃剑。 |
| family_16 sailor | 天灾必带元素轮转（同卡风/雷/雨分工或互增幅），禁无元素物理伤害。 |
| family_17 chanter | 契约必须双边成文（写规则 + 违例惩罚字段）；不拿诅咒/腐蚀——净化是本职不是兼职。 |
| family_18 reader | 全知是「看」不是「改」——reveal 只显形不附加；模仿排除权柄技能。 |
| family_19 spectator | 控制/读心必带位格前提或位格差缩放；空想产物必有「非真存」缺陷（短寿/消散）。 |
| family_20 supplicant | 放牧的灵魂必须可追偿；血肉经济只许「自残换效」，不拿治疗本职。 |
| family_21 criminal | 恶欲值只涨于「放纵」（敌方行动/伤害/施法），不来自自伤；恶魔投影必须走仪式刻印 f(N) 映射。 |
| family_22 prisoner | 诅咒必带反照/代价；异类形态谱系栈单调不可逆（推栈不回头）。 |

## 三、分叉维度索引（撞车裁判依据）

共享维度各家族诠释一句话；英雄展开时同维度新卡必须沿用本家族诠释，跨家族撞车按此表仲裁。

| 维度 | 各家分叉诠释 |
|---|---|
| translocate | family_09=放逐时空乱流；family_04=拉入镜中世界；family_08=自身放逐（历史孔隙）。 |
| write_rule_slot / modify_rule_slot | family_06=立新规（禁与价，不改文本）；family_07=扭曲既有规则槽（先立后破）；family_08=嫁接重组（换宿主不改文本）；family_12=物理规律改写（重力/材质/距离）。 |
| filter.unitType | family_01=恶魔克星（晨曦克制）；family_02=灵视克灵体亡灵。 |
| take_control / target_override | family_10=寄生顶替（以假代真）；family_05=征服臣服（指挥调防）。 |
| advance_clock | family_13=命运回拨（保存重启）；family_17=仪式昼夜；family_03=赶夜入夜。 |
| reveal | family_18=显形解析（先解析后放大）；family_02=灵视；family_01=破隐识破（不藏只破藏）。 |
| snapshot / restore_snapshot | family_09=记录存档点（记录/再现）；family_13=保存重启循环。 |
| transfer_status | family_11=神秘搬运；family_22=诅咒转移（curse_link）。 |
| modify_damage | family_19=想象干预伤害走向；family_07=扭曲伤害定义。 |
| move | family_16=怒海位移；family_04=镜中换位。 |
| conceal 潜匿 | family_04=镜中潜行；family_10=欺瞒隐身；family_03=夜幕；family_05=猎手潜伏；family_01 走语义分叉（伪装非 conceal：targetOverrideImmune + 出手自破）。 |
| spawn 召唤 | family_12=造物自组装；family_15=成熟召唤；family_19=空想具现（强制非真存缺陷：短寿/白板/消散三选一）。 |
| on_kill | family_02=死亡清点；family_01=收割；family_05=战果清点。 |

## 四、剔除说明

- 旧设定专名全数剔除；家族身份以机制语义自立。
- 签名键判定口径（prim:/sref:/flag: 等 AST 键定义）与 score.py 耦合，v2 评分脚本未复活，暂不迁。
- 现状差距评估、骨架手术实测数据（三件套占比/途径均距等）、机制/状态层所有权矩阵均为快照性质，留参考源按需查。
