## 一·五、本质与在册机制映射

> 主人给定「核心本质 + 能力调性」，映射到在册机制（2026-10-31 起逐家族过稿；命题定稿在映射完成后另立一轮）。

### family_01 warrior

- **核心**：黄昏、衰败、终末、巨力、落幕——不是光明系，是光明的终点；黎明之光只是黄昏前夕的回光。
- **调性**：极致肉身与防御（肉身最强一档）；破晓净化；高段自带衰败领域、崩坏万物。
- **在册机制映射**：martial = 极致肉身/武器耐久线（格斗连击、武器大师、破甲重击、黄昏巨剑）；guard = 正面承伤与守护（死斗、守护状态、银色全身甲、黎明铠甲）；twilight = 老化 → 崩解 → 将死宣判（迟暮产层；万物崩解、神罚、黄昏重生、处决登记读层兑现）；holy 仅现于破晓净化语境（神圣·荣耀、黎明铠甲），不展开为光明系。
- **家族独占机制**：① 替承族——守护姿态（替承+弃攻买墙）、守护威压（承伤叠层）、无形墙壁（守卫姿态挡投掷）、黎明铠甲自成守护，全库唯一的伤害路由体系；② 装备浓度——装备两槽为全局机制，但「装备即本体、耐久是消耗品」的玩法浓度全库独此一家（3 件装备卡 + 武器大师 + initialEquip）；③ 衰败引擎——老化叠层 → 崩解 → 神罚 → 黄昏重生，全库唯一 aging 系；④ 黄昏回光 holy——裁定 #1 语义独占（chanter 持正午，其余禁 holy）；⑤ 零吟唱节奏——castTime 恒 0 的家族口径。
- **家族命题（2026-10-31 定稿）**：**黄昏中转站**——伤害经由我结算：替承把队友的伤接过来，对撞把贴身者的血换回去，装备耐久与护甲池是手续费；敌人与我交手即开始落幕（衰败记账）。可操作变量：① 承接路由（守护给谁、墙挡什么、对撞贴谁——高攻高防时换血最大化）② 手续费节奏（武器耐久/护具池的消耗与补给）③ 衰败铺层时机。输面：多点开花承接过载；装备断线 = 攻防同时下线；被风筝则换血优势归零；替承与买墙是双向绑定——保谁弃谁。
- **招牌下放**：将死宣判（处决登记）为英雄·壹招牌（hero-level），不上升家族命题。

### family_02 corpse_collector

- **核心**：死亡、亡灵、摆渡、永眠、生命终点——纯粹生死权柄，一切生命的最终归宿；暮河三系里最直白的「终末」。
- **调性**：招魂、亡灵军团、灵魂掌控、生死切割；主打亡灵大军与灵魂审判。
- **在册机制映射**：家族签名 = filter.unitType 灵视克制 + on_kill 死亡结算（身份卡 §一）。选材池机制面（源 43 卡已勘探）：undead = 亡灵军团（骷髅/活尸/亡魂三蓝本 + 召唤 cap + 维持费）；end = 死亡账本（铺账 → 催账/收账 → 权柄合并结算，可净化拆账），摆渡与生死切割语义由阈值处决承载（摆渡·对视、死亡宣告）；spirit_sight = 灵视克制（对隐匿 ×1.5 + 识破驱散）；corpse = 尸体特质（自持坦度，多卡以「自带尸体特质」为门槛联动）。红线不冲突：死亡是过程不做即死；军团受 cap；账本必须可拆。
- **家族独占机制**：① 死亡账簿——全库唯一「铺账 → 催账 → 合并结算 → 可拆账」死亡记账体系，摆渡/生死切割由阈值处决承载；② 亡灵军团蓝本族——骷髅/活尸/亡魂三蓝本 + 召唤 cap + 维持费经济，与 apothecary 兽群划界（血肉异变活体 vs 亡者复起）；③ 灵视克制——filter.unitType 灵视（对隐匿/灵体 ×1.5 + 识破驱散），归属已登记 §一；④ 尸体特质门槛经济——以「自带尸体特质」为联动门槛的自持坦度 + 尸体通货网络；⑤ on_kill 死亡清点——与 family_01=收割、family_05=战果清点语义分叉（§一·六）。
- **家族命题（2026-10-31 定稿）**：**死亡账房**——凡在灵视内死去的都进我的账：亡灵军团是应收账款的具现，生死切割是到期催账，摆渡是结清送终；账合拢时一次结算（权柄合并），账被拆了就要重记。可操作变量：① 入账路由（谁死进账、灵视范围怎么扩）② 催账节奏（阈值处决的时机与代价）③ 军团维持经济（召唤位/维持费收支）。输面：账本可拆 = 全场净化是克星；军团受 cap 铺不开数量；生前无输出——没人死就无账可记，怕速攻压制局。
- **英雄预留**：死亡账房为家族命题；处决登记类大招下放未来英雄（hero-level），不上升家族命题。

### family_03 sleepless

- **核心**：黑夜、安眠、隐秘、守护、长夜终末——掌控夜晚、梦境与沉寂，让一切归于安眠；寂静与守护的终末体系，克制疯狂与躁动。
- **调性**：夜视、潜行、梦魇、安抚与沉寂。
- **在册机制映射**：家族签名 = on_phase_change 相位触发 + advance_clock 拨时入夜 + secrecy 隐秘资源深化（身份卡 §一）。已回填蓝本（悬空读层迁入派系池）：covert_veil 潜匿（出手自破）、occult_seal 隐秘封印（双向绝对封印）、conceal_authority 隐秘权柄（授予潜匿 + conceal 类不可驱散）——三张已被 h02/h03/h05 跨系读层，是现成的枢纽资产。选材池机制面（源 34 卡待层一逐张勘探）：夜幕相位引擎（advance_clock 推夜，收益随相位起落、正午弱项对称），夜色层数存取（secrecy 夜里存白天花），梦魇压制（fear/dread 语义——与 monster「厄运惊惧」共享 fear 系但语义分叉：那边是命运反噬的惊，这边是安眠的惧，裁定 #7 已划界：sleepless = 梦魇压制 fear/减益向），安抚沉寂（silence 系，反躁动——克制 monster 疯狂/命运反噬面）。红线不冲突：不走 holy/火；暗夜收益必随相位起落。
- **家族独占机制**：① 夜幕相位引擎——advance_clock 拨时入夜 + on_phase_change 收益随相位起落（正午弱项对称），全库唯一「主动改天时」；② 夜色层数存取——secrecy 夜里存、白天花的潮汐账户；③ 梦魇压制——fear/dread 安眠向（与 monster 命运反噬惊惧分叉，裁定 #7）；④ 安抚沉寂——silence 系反躁动；⑤ 隐秘三蓝本族——潜匿（出手自破）/隐秘封印（双向绝对封印）/隐秘权柄（conceal 类不可驱散），已被 h02/h03/h05 读层的现成枢纽。
- **家族命题（2026-10-31 定稿）**：**长夜值守**——白天我蛰伏攒夜（secrecy 入账），入夜我开门营业：梦魇压躁动、封印锁失控、夜色换收益；天亮我收摊认弱（正午弱项），但账上存的夜还在。可操作变量：① 拨时节奏（几时推夜、相位落到哪档）② 存取比（secrecy 夜里存多少、白天花多狠）③ 压制选品（封谁、惧谁、锁谁）。输面：正午弱项是被打窗口；拨时是全队共享的——推夜也喂对手夜色经济（若有）；蛰伏期无作为，怕速攻。
- **英雄预留**：长夜值守为家族命题；英雄级招牌（如梦境侵蚀类大招）下放未来英雄，不上升家族命题。

### family_04 assassin

- **核心**：畸变、魅惑、命运扭曲、极致灾祸欲望——高速高诡、极致灵动；自带灾祸属性，越挣扎越容易坠入畸变；混乱、欲望、灾厄体系。
- **调性**：幻术、魅惑、敏捷、命运扰动、异变。
- **在册机制映射**（英雄·贰在册）：form = 异变与形态（影/雾/血三形态轮转、隐形与阴影躲藏、女巫之形——自身魅惑与误导不可驱散）；mirror = 幻术与命运扰动（镜映借序：镜子替身、魔镜占卜、镜中迷宫、镜中世界；charm_axis 魅惑满层转不可驱散、bewitch 误导——把刀递向自己人即微观命运扭曲）；plague = 灾祸属性（黑焰、冰霜、疾病——灾祸欲望的具现，疫由焰生）；敏捷面 = 羽毛轻盈（受击后撤消耗）与鹰的视力。红线不冲突：镜子语义绑定、输出必带闪避/替身/换位——正是「高速高诡、不正面站撸」的机制表达。派系底座呼应：战祸「借力」——借对手之招，灾祸自携。
- **家族独占机制**：① 镜子语义绑定——镜子替身/拉入/穿梭三选一强绑定，全库唯一「镜面即武器」；② 形态轮转族——影/雾/血三形态互斥轮转（formGroup），形态绑定状态与属性改写走标准挂载/回滚；③ 魅惑与误导——charm_axis 满层转不可驱散、bewitch 递刀（微观命运扭曲），与 spectator 认知改写划界：这边战场层递刀，那边梦境层改认知；④ 灾祸自携——黑焰/冰霜/疾病三灾随身（plague 具现），输出必带灾祸属性；⑤ 高速身法——羽毛轻盈（受击后撤消耗）+ 鹰视，输出必带闪避/替身/换位其一（红线即机制）。
- **家族命题（2026-10-31 定稿）**：**灾祸快递**——我不站桩，我投递：镜子是取件码（替身接单），魅惑是签收人（误导递刀），灾祸是包裹本身（黑焰冰霜疾病三选一）；你打我总打错地址（闪避/后撤/替身）。可操作变量：① 快递路由（镜子链怎么走、替身放哪）② 签收策略（魅惑叠谁、误导递谁）③ 包裹选品（三灾配比）。输面：身板脆——被命中即大出血；镜子链一断全场迷路；灾祸是双刃剑，plague 越挣扎越畸变。
- **英雄预留**：镜子体系为家族独占机制；「镜映借序」具体玩法为英雄·贰招牌（hero-level），不上升家族命题。

### family_06 arbiter

- **核心**：律法、惩戒、秩序、裁决、规则审判——依靠世界法理审判敌人：锁定罪行、制裁违规、封印失控；硬性秩序，专治混乱、失控、邪祟。
- **调性**：封印、惩戒、执法、压制罪恶。
- **在册机制映射**（英雄·叁在册）：decree 轴 = 审判核心——write_rule_slot 立「禁与价」（no_skill/no_attack 写入 Rules[3] 槽）+ 违例 punish 载荷（decree 状态承载惩罚：精神伤害 + 枷锁），立规/囚禁/惩戒/禁制追击同族；jurisdiction 轴 = 执法空间——辖区（zone_jurisdiction 数值辖区：己方增益/敌方迟滞）、位格管辖与位格律令（位格低于我者：我减伤、我增伤——执法有门槛）；inquest/support = 锁定罪行——屈服、精神刺穿、过目不忘（marked 破绽标记，读层追加伤害）；order 秩序度 = 世界法理账户——四张写入卡供源，秩序推高则律令乘区放大（法系越稳罚越重）；封印失控 = 废除/基石规则/立规封技，满月显形破隐匿对治邪祟。红线自洽：只立禁与价、违例必罚、豁免必付代价（豁免账/权威转移）。
- **家族独占机制**：① 立规族——write_rule_slot 立「禁与价」的正统立法权（规则槽四家四分：06=立法、07=扭曲、08=嫁接、12=物理规律，§三索引）；② 违例惩罚载荷——decree 状态承载 punish（精神伤害 + 枷锁），「违例必罚」结构化；③ 辖区数值空间——zone_jurisdiction 执法区（己方增益/敌方迟滞），与 lawyer 王权疆域、planter 大地、sailor 海域四分（裁定 #4③、#6）；④ 秩序度账户——order 世界法理账户，秩序推高律令乘区放大；⑤ 位格管辖——位格执法门槛（位格低于我者我减伤增伤）。
- **家族命题（2026-10-31 定稿）**：**秩序法庭**——我不攻击你，我立法你：规则槽是我的法条，违例自动开庭（punish 载荷），辖区是我的执法空间，秩序度越高压迫越重；你越挣扎越违规。可操作变量：① 立法选品（禁什么、价码几级）② 执法布局（辖区铺哪）③ 秩序经营（供源节奏）。输面：规则槽只有 3 个——法条拥挤；立规有豁免条款（豁免账/权威转移）= 可被买通；秩序度断供则罚则缩水；位格门槛——高阶对手执法无效。
- **英雄预留**：秩序法庭为家族命题；法令规则槽具体玩法（英雄·叁轴玩法）为英雄招牌，不上升家族命题。

### family_08 seer

## 一·六、撞车裁定录（2026-10-31 主人全批）

1. **光明语义二分**：holy 两家共用——warrior = 黄昏回光（小剂量、破晓净化语境），chanter = 正午圣光（大剂量、团队增益/驱散亡灵）；其余家族禁 holy。chanter 双柱成立：净化本职 + 契约窗口。
