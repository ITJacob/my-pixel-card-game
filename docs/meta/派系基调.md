# 派系主基调（9 派系）

> 派系级底座：家族身份卡（家族级）的上层约束，生成工作流层〇的输入。
> 底座只定原型气质，不牵扯具体机制细节；机制下沉到家族身份卡与英雄命题层。
> 九个派系已命名落稿（2026-10-30）：暮河 / 战祸 / 律庭 / 时隙 / 禁知 / 星钥 / 血巢 / 奇点 / 欲狱。

## faction_01 派系·壹

**万物走向终点、落幕归永暗。**

收束、沉降、终局之美——光是借来的，迟早要还。

## faction_02 派系·贰

**冲突、战争、灾厄毁灭。**

火上浇油，越打越旺；灾不是意外，是常态。

## faction_03 派系·叁

**秩序、王权，秩序与崩坏。**

立规矩的人也跪在规矩里；王权与崩塌是一体两面。

## faction_04 派系·肆

**时空、历史、命运的奇迹与漏洞。**

万物皆有缝——线可以牵，时间可以预排，借来的迟早归还。

## faction_05 派系·伍

**荒芜、禁忌、会致疯的隐秘知识。**

知道得越多越接近门槛；星空是共享的，先到者立法。

## faction_06 派系·陆

**星辰命运，开启与通道。**

命运是一扇摆动的门：押对方向门开，押错方向门关。

## faction_07 派系·柒

**血肉生命的孕育与蜕变。**

一切都是孕育——急不得，也抢不走；以时间换强度。

## faction_08 奇点

**万物从这里诞生（创世·全知）。**

风雷雨按序降生；窗口之前，万物未成。

## faction_09 派系·玖

**欲望、堕落、诅咒、禁锢。**

力量都是债——要血肉、要放纵、要反照。
