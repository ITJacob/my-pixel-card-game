## 全库通则（随基准定档裁定）

- **近战必然对撞**（INV-29）：近战 = 贴身肉搏，对撞在攻击触发瞬间必然发生，无射程豁免、非反击。
- **武器接管普攻**：持武器时伤害按武器档结算、覆盖派系基础攻击，派系偏差仅空手生效；武器射程/元素随武器，对撞随 reach。
- **CD 不锁机会**：任何 CD 只锁该行为本身，冷却期内行动机会照常用（编队上下文「吟唱与冷却」）。
- **移动插入语义**：移动 = 插入目标位、后缀顺移补位，目标路满则拒，无交换无挤占（战场上下文「默认主动移动」）。
- **自耗钳 1**：一切自残类代价（暮河空手/血巢奶/禁知反噬）最低钳 1 血不致死，差额免单。
- **选靶流程**：行动机会 → 选行为 → 选靶请求出候选集 → auto 按 sort / manual 玩家手选（共享内核参数 §一）。
