战场玩法

两方在定长队列里按行动条轮流出手。一切行为走同一条结算流水线。

一、场地

  • 坐标 = 阵营 + 路 + 序号。上下两路，每路 4 格，0 号靠中线，全场 16 格。
  • 单位占格。区域占坐标。界域不占格。
  • 占位只经 Placement。变更后同一步内紧凑，队首不留空。
  • 移动 = 插入目标位，后缀顺移。满路拒绝。跨阵营禁止。换路只在上、下两路之间。
  • 区域监听占用变化，不监听移动动作。

二、时间与机会

  • tick 先推进世界：回复、冷却、吟唱、状态与区域计时、界域计时。推进完才授予机会。
  • 行动条按速率增长，严格越过阈值得一次机会。同 tick 每单位至多一次。
  • 先手 = 双方各自排序后交替合并。
  • 一次机会内可连续行为，直到无可用行为或主动结束。
  • 机会获得与结束都触发；机会作废也触发。

三、行为

  • 可选底集 = 槽内技能 + 普攻 + 移动 + 跳过。
  • 过滤顺序固定：冷却 → 在线装备 → 强制白名单 → 吟唱 → 能量 → 行动条。
  • 选靶：候选池先过滤，再收缩。手动候选过多时等待玩家；无玩家按兜底排序。
  • 转向单跳、防环。伤害随转向，状态类效果留原目标。
  • 分流五路：直接结算 / 注册区域 / 召唤落位 / 注册界域 / 放逐。
  • 群攻 = 每个目标一条独立结算链。近战必定对撞，两条结果同时应用。

四、伤害

  • 五段固定：护盾 → 护甲 → 抗性 → 防御 → 乘区。次序不可改。
  • 护甲只挡有形伤害。DoT 只过抗性与乘区。致死直连跳过全部减伤。
  • 抗性钳制在 −50% 到 +75%。
  • 链内只读不写；结果交既定节点落地。

五、单位

  • 六池：生命、能量、护盾、护甲、迷失、恶欲。
  • 属性四项：力量、敏捷、智力、位格。修正按实例记账，撤销回到写入前的值。
  • 状态 = 定义 → 授予 → 实例。类别只有正向与负向。驱散只清实例。
  • 死亡链：禁复活 → 替身 → 致死保护 → 亡语，命中即停。
  • 装备两槽：武器给攻击加值与耐久，护具给护甲池。同槽顶替，下线才起共用冷却。
  • 召唤物占格、有血量、可被攻击。超上限时最早在场者消散。

六、战场层

  • 界域压制栈：底层不可驱散，英雄层常驻，覆盖层压栈。只有栈顶生效，解除后下层恢复。
  • 规则槽 3 条：触发 + 违约惩罚 + 豁免。双方同受，豁免靠购买。
  • 区域：坐标陷阱，占用变化触发，次数确定。
  • 量表：隐秘、秩序、命运、光照、冲突。秩序初始 5。
  • 时钟跨相位派发触发；光照覆写等同跨边界。

七、未定

  • 胜负、平局、超时、战斗结束触发点。
  • 开局配置：队伍人数、站位、槽位装入、初始界域、随机种子。
  • 两路的路序：跨路回退取第一条非空路时，上路还是下路优先。
  • 能量上限与回复档；召唤位基数；装备下线系数；迷失档位。
  • 敌方行为与目标选择的输入来源；手动选靶超时规则。
  • 数值标定全缺，无法试玩。
  • 状态类别文档写二元、数据用十二值；战场量表取值有 4／5／6 三种。
  • 基层界域无数据载体；护具槽 0 张卡；缴械、装备回收、装备触发点、机会结束触发均无卡可验证。
  • 部分卡面有机制描述而载荷为空；秩序量表存在恒不成立的条件分支。

本页只写规则本身，不含过程、版本与备注。
